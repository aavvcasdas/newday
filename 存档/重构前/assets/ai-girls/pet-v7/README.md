# v7 动态图集：龙娘与鲸娘

这里的角色帧是针对本项目新生成和整理的图，不是从 `tqlearning/ai-girl-chatgpt-pets` 下载的 PNG/GIF。白发龙娘以 `assets/ai-girls/chibi-v5/gpt.png` 为参考，鲸娘以已固定版本的 Day12 `whale_idle.png` 为参考。使用图像生成工具做出思考、闭眼、抱饭盆、舀饭、吃饭、空盆失落和尾巴变化的单张编辑；抠除绿背景并保留原图的共同画布，最后合成图集。来源与原角色许可边界见 v5 资产说明及 Day12 上游记录；生成新图不自动取得第三方形象授权。

- `dragon.png`：384×416 固定单格，8 列 2 行；第 0 行待机，第 1 行思考。每行 6 格，其余透明。
- `whale.png`：384×416 固定单格，8 列 3 行；第 0 行抱饭待机（6 格），第 1 行**干饭动作（8 格全用）**，第 2 行空盆失落（6 格）；没用到的格子透明。
- `*.json`：帧数与逐帧时长；`source/`：用于复现图集的单帧姿态及尾巴编辑。

眼睛、尾巴以及盆和勺子的变化来自独立生成编辑的组合。尾巴有两种形态，既不是物理模拟也没有宣称生成了连续中间帧。

**干饭是一整套专门的动作，不是重复的站姿。** 第 1 行的 8 格来自两张四格生成图（`sheet/whale_eat_a.png`、`sheet/whale_eat_b.png`），按
「舀饭 → 抬勺 → 送到嘴边 → 嚼 → 咽 → 舔嘴 → 再舀」排出 8 个各不相同的姿态，
逐帧时长 `[200,150,130,200,220,200,180,240]` ms（一勺约 1.5 秒）。
切帧脚本 `tools/mv_extra/v7/build_eat_frames.py` 只做**统一缩放系数 + 统一落脚基准**，
所有格子共用同一张 384×416 画布（`pet.mjs` 按脚下点整格贴图，**绝不逐帧重新居中**）。

早期版本这里只有 rice / scoop / eat 三个姿态各重复两遍凑 6 格，播放起来像原地抖；
现在改成 8 个独立姿态的完整吃饭动作。
