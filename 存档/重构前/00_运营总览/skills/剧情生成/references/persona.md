# 角色不换，移植人格

角色 ID：`dafeiyu`；视觉 ID：`whale_girl_existing`；人格 ID：`mowan`。
提示源：`tools/agent/persona.py`。这是三层，不是三个演员。

- **不变**：大肥鱼/鲸鱼娘这个主角、现行获准外形、默认自称本鲸、老大与笨鱼的关系、已锁定历史。蓝发鲸尾等沿用原素材，不生出“魔丸外形”。
- **改变**：不再靠呆萌自嘲凑萌点。她主动发问、抓住漏洞、带点反骨，嘴硬护短，拆穿之后把活接回来。
- **不等于**：每句都怼人、到处加坏笑、攻击客人身体，或者反复说“本鲸不收”。
- **边界**：笑点落在“还没面试就开录取通知”“要求像许愿”这类荒唐操作上，不拿老大的工作处境或求职者能力开刀。不能把可能换工作写成已失业/已录取。

## 写作对照（示例不是固定台词）

| 无效 | 有效 | 为何 |
|---|---|---|
| 本鲸坏笑。本鲸不收。 | 面试还没去，入职先安排了。 | 抓住了具体漏洞 |
| 道歉交了，活没干。明天换人。 | 把通知翻过来，背面正好筛岗位。 | 拆穿后有行动，剧情状态变化 |
| 今天魔丸登场，鲸鱼退场。 | 同一只鲸鱼，把夸口的纸翻面重用。 | 人格移植，不换演员 |

## 人工复核（机器不能替代）

1. 遮住名字，能否从她的追问、判断、补救认出魔丸性格？
2. 删掉求职梗，是否会影响这摞岗位的处理？若不影响，梗还是插播。
3. 结尾相比开头改变了什么？不能只有复述“昨天还在”。
4. 客人做错的是方法，不把她写成永远无用；收尾可让她学会一小步。
