**人物和动作**：主角继续使用 Day12 鲸鱼娘姿态，Claude 使用已有 Q 版姿态；其余伙伴根据仓库现有形象生成 Q 版。主角有走步、执烟花等姿态切换，Claude 使用多姿态，其他伙伴用轻微骨骼与手势动画。不是每个人都有原生逐帧动画，手势仍受单张插画限制。画面并未使用 `tqlearning/ai-girl-chatgpt-pets` 图集：该项目虽有九种动作，其图像授权未确认；详见 `tools/mv_extra/v5/README.md`。

**参照原片调整**：开头恢复灰色拼图氛围，约 17.4 秒提前进入雨伞和长椅场景、增加伞骨及伞缘细节，歌词底条改成浅色纸卡。其余仍是代码重绘而非逐像素复刻；原片长椅坐姿在本版仍是站姿，若继续追求原片一致性需要另制作坐姿资产。

**核验**：完整解码为 1920×1080、30fps、1681 帧；AAC 音轨与来源 bitstream 校验一致。逐镜与每秒选取片段抽样的动作测试通过；这些数值测试不能替代全片人工观看及听觉审阅。
