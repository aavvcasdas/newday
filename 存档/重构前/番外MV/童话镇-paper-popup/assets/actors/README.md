# Existing project character cut-outs

These transparent PNGs are palette-decoded crops of the existing character frames in `番外MV/童话镇/src/sprites_data.js`. They are character artwork only; this paper-pop-up project continues to use its own scene, world, timeline and renderer. `src/art.js` fits each sprite into a canvas and applies a paper-board edge plus white cut line.
