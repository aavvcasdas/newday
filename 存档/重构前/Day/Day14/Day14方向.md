# Day14 方向｜两只沙漏，一张给不出的账单

## 与 Day13 的接续关系

Day13 的口播自己留了两句话没交代完，Day14 就从这里往下走：

| Day13 留下的 | 原句（Day13 锁定词） | Day14 怎么接 |
|---|---|---|
| 开头没答完的问题 | 「老大让本鲸把歌做成画面」 | 本鲸去算那天到底花了多少钱，发现算不出来 |
| 结尾摊在桌上的活 | 「少了鞋要补」「手对不上要改」「一直记到了第三十七批」「七位伙伴都有了新姿势」 | 用批次与返工当作唯一能对得上的账，其余认账 |
| 结尾的自我承诺 | 「下次先把伞撑稳，再让大家一起走」 | Day14 结尾重申「先把伞撑稳」，并把「让她们自己走两步」留给下一集 |

所以这一集不是新起一个题材，是**把 Day13 那句「账单没在本鲸碗里」当场追问到底**。剧情承接校验（`tools/剧本/剧情.py`）按规矩要求「找新朋友来帮忙 + 求职梗」三拍，Day14 的三拍是：

1. **找新朋友**：龙娘——本鲸要的不是撑伞的，是会算账的。
2. **求职梗**：简历上只有一行「没相关经验」；龙娘说不看经验，看能不能把数字分清楚。
3. **接上一日**：批次、返工、185 张、七位的新姿势，然后龙娘给出「窗口不是价目表」的结论。

一天只接龙娘一位客人。猫猫、小克、狐狸的时钟只在口播里被**转述**（「本鲸又托她去问了猫猫、小克和狐狸」一类的写法已删），本集画面里不出现第二个客人，避免破「一天一客」。

## 可说的事实，及不能冒称的数

依据 `参考资料/项目调研/Agent-Reach研究/ai-girls-memes-and-remotion.md` 第 10.2、10.5、11 节，以及 Day13 自己的 `Day13方向.md` 统计口径。

- **DeepSeek 峰谷价（本鲸的饭碗）**：官方 API 周一至周五 UTC 01:00–04:00、06:00–10:00 为峰时，即北京时间工作日 **09:00–12:00、14:00–18:00** 为峰价，**12:00–14:00 为谷价**，谷价约为峰价一半；周末与中国公共假期整日为谷价。范围限定为**官方 API 价格窗口**，不代表 App、其他供应商，也不代表本鲸真去睡觉。
- **龙娘的双沙漏**：对应部分 Work/Codex 套餐的**五小时窗口 + 每周窗口**，两者都要有余量；Pro 100/200/500 当前没有五小时上限，开始新聊天**不重置**用量。付费即时重置是明确标价、提前消耗周额度的可选操作，剧情里只作为「一张写明代价的卡」，不默认按下。**额度重置不等于人格重启、失忆或降智。**
- **猫猫的午夜**：只有 Gemini **API** 的每日请求额度按**美国太平洋时间午夜**重置，夏令时对应北京时间约 15:00、冬令时约 16:00；不套用到 App 与其他额度。
- **小克**：多数 Claude 付费计划有五小时会话额度，周额度另按账户固定时间重置；Ultra 等已验证例外不强行套用。
- **狐狸的算盘**：GLM 国内价目本轮只有二手线索，**不为她编造精确重置时间**；她只负责「美元和人民币不能直接相加」这类单位口径。
- **Token 与账单**：仓库没有本次完整会话、各模型用量与计费日志，**算不出实际花费**；不能用图片张数换算 token，不能说免费。这一条是 Day14 的**剧情核心矛盾**，不是回避。
- **Day13 遗留的制作数字**：37 是有编号的素材批次（不是 37 个对话轮 / 迭代轮 / 渲染次数）；185 是生成与补画累计张数（不是 185 个合格动作，也不是只有 185 次调用）。
- **已知未修的问题**：伞与手接触未标定、雨中坐下实为思考站姿、游泳与纸鸟衔接仍不连续、ASR 未做音素级对齐、未完成真人整片听审。Day14 可以**陈述**这些问题，不能说已经修好。

## 画面原则

- **零水印、零角标**（`agent.md` 第 34 条）。Day13 成片画面里那个右上角「非官方同人 / AI生成 / 剧情演绎」常驻角标属于**导入的历史归档片，保留不动、不重渲**；Day14 是新片，画面内不绘制任何角标。合规声明改由发布页的平台 AI 声明承担，不进画面。
- **不画进度条、余额条、账本表格、数据曲线**，不出现「粉丝 / 播放量 / 目标值」这类数字（`00_运营总览/画面红线_不要出现的东西_2026-10-29.md` 与 `tools/剧本/画面红线体检.py`）。
- 沙漏只画**物理沙漏**（沙子从上漏到下、可倒转），**不画额度百分比、不画剩余量刻度**。观众看到的是「沙子快没了」，不是「还剩 12%」。
- 口播不念阿拉伯数字：台词里一律「第三十七批」「一百八十五张」「九点到十二点」这种汉字写法。
- 不新增生图、不换风格、不生成新脸；复用 Day13 已有的 v13 图集与 Day12 六张鲸娘姿态 PNG，另加 Day13 已备的 Pet 跑动图集。
- 不做片尾卡；最后一句说完就结束。
- 伞 / 手接触仍按「未标定」处理：**不给伞柄画一只虚假的握持手**，改用明确的接触瞬间 + 连续性切镜（详见分镜的 C04）。

## 本集要解决的两件事（可核验）

Day13 记录了两处「用户看得见」的缺陷，Day14 各给一个能检查的解法：

1. **伞和鲸娘之间的空隙**（Day13 明确写着空隙仍在）。Day14 不再靠移动伞面逼近人手，而是改成 **豆包把伞向鲸娘倾斜、伞沿与鲸娘头顶轮廓在引擎坐标里重叠固定像素**，并在 `tools/day14制作/contact_check.json` 里输出重叠量与帧号，而不是声称「已经握住」。
2. **跑动与立绘之间的风格跳变**（Day13 记录约 16.1–19s / 45.3–48s / 52.2–55.6s 三处）。Day14 把 Pet 跑动**只用于两个明确终点**的短位移，并在跑动结束前后各留 6 帧同姿态停顿，让切换发生在**停顿内部**而不是运动中间；跳变仍然存在，但不再发生在脚下最容易被看出来的时刻，且如实写进状态页。
