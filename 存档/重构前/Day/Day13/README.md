## 复现

```bash
npm ci --prefix tools/mv_dayu/remotion
# 缺字体时按已存 manifest 从固定来源恢复
python3 tools/day12制作/restore_sample_assets.py --manifest tools/day12制作/production_assets.json
node tools/day13制作/prepare.mjs
node tools/day13制作/render.mjs
# 需指定 FFMPEG、FFPROBE、PYTHON；后者的环境需 numpy
bash tools/day13制作/finish.sh
```

同一遍完整帧以600帧范围串行渲染，减少浏览器内存积累；拼接时使用每段实际20秒并仅映射视频流，避免静音音轨让后续段整体漂移。最终配音未被拆段或改变语速。旧目录中的台词候选和 Day12 保留，不是本片字幕输入。
