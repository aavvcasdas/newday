# 王国危机动作试剪

这是制作中的 **14 秒粗试剪**，不是完整歌词 MV，也不是精修或最终风格。鲸鱼娘为勇者，GPT 龙娘为恶龙，Gemini 暂定为公主，Claude 暂定为国王。画面里的连线仅表示劫走关系，不代表角色手部真实接触。

- 从原视频约 20–34 秒取音频，AAC 整包复制：程序验证源和输出的 603 个音频包字节一致；包边界会使切入点略偏于 20 秒。
- 960×540、30fps，14 秒视频；简化画面用 Pillow 绘制、PyAV 编码，角色使用仓库既有 v14 图集。原片未作画面搬运。无常驻水印。
- 该段没有精确逐句时间轴，暂不添加歌词字幕；画面事件只按参考帧近似安排，**尚未人工动态审看、听审和同步验收**。勇者的剑是独立绘制道具，没有声称接触手掌。
- 全曲、歌词字幕、姓名对话、游戏旅程与龙穴尚未制作。需要后续完整听审原音并逐镜打点，补足马、骑乘、王宫和龙穴动作，再交付完整视频。

复现（Python 3.11+，安装 `av` 和 `Pillow`，并保证仓库根目录的 `达拉崩吧.mp4` 与角色素材存在）：

```sh
python tools/mv_dalabengba/render_sample.py
```
