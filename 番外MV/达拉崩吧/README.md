# 《达拉崩吧》 — 16-bit Pixel RPG 复刻版 MV

基于 `lemo-opuscar` 的 **`pixel-rpg`（16-bit 超任像素 RPG）** 纯代码渲染管线（`320×180` 场景逻辑层 + **`640×360` 高清晰度轻像素角色层**、`×3` 严格整数临近放大输出 `1920×1080 @ 24fps`、无任何角落水印），忠实复刻参考视频 `达拉崩吧.mp4` 的动态立体书开场、多切镜分镜节奏、鲸鱼娘跑地图演出与双段完整歌词。

## 目录交付清单

- **`dalabengba.mp4`**：`1920×1080`、`24 fps`、`132.77s` 正式成片（原曲音轨 + 87 处帧级 16-bit RPG 动作音效，双遍 `loudnorm` 母带校准至 `-14.1 LUFS`，`grain=0` 纯净锐度，零水印）。
- **发布封面（零水印、零生图、自动安全区校验）**：
  - `3:4` 竖版（`1080×1440`）：[`封面/达拉崩吧MV_封面_3比4.png`](封面/达拉崩吧MV_封面_3比4.png)
  - `4:3` 横版（`1440×1080`）：[`封面/达拉崩吧MV_封面_4比3.png`](封面/达拉崩吧MV_封面_4比3.png)
  - 验收报告与生成脚本：[`封面/封面_验收.json`](封面/封面_验收.json)、[`make_covers.mjs`](make_covers.mjs)
- **[`发布文案.md`](发布文案.md)**：承接 `Day13`（碗边剧组 / 不站桩跑起来 / 老大的白饭）的主推标题、多平台备选标题、简介文案与置顶评论。
- **`poster.jpg` & `character_sheet.jpg`**：`1920×1080` 剧照海报帧与八角色轻像素设定总表（`?sheet=1`）。
- **`dalabengba.srt`**：46 条精确时间轴外挂歌词字幕（与片内像素歌词条严格同源）。
- **`TREATMENT.md`**：完整导演阐述、调色板 LUT 规范与 26 镜逐拍分镜表。
- **`index.html` & `src/`**：纯代码双层像素引擎（`sprites_data.js`、`px.js`、`glyphs.js`、`timeline.js`、`cast.js`、`ui.js`、`scenes.js`、`main.js`）。
- **`mix.py` & `build.sh`**：一键复现整套可读性门禁、音效合成混音、并行渲染与母带封装脚本。
- **`CREDITS` & `fonts/LICENSE.font.txt`**：字体（Fusion Pixel Font，`OFL-1.1`）与制作署名。

## 一键重出成片与封面

```bash
chmod +x 番外MV/达拉崩吧/build.sh
sh 番外MV/达拉崩吧/build.sh
node 番外MV/达拉崩吧/make_covers.mjs
```
