# 《达拉崩吧》 — 16-bit Pixel RPG 复刻版 MV

基于 `lemo-opuscar` 的 **`pixel-rpg`（16-bit 超任像素 RPG）** 纯代码渲染管线（`320×180` 索引帧缓冲、`×6` 严格整数临近放大输出 `1920×1080 @ 24fps`、无任何角落水印），忠实复刻参考视频 `达拉崩吧.mp4` 的全部叙事分镜、喜剧节奏与双段完整歌词。

## 目录交付清单

- **`dalabengba.mp4`**：`1920×1080`、`24 fps`、`132.77s` 正式成片（原曲音轨 + 83 处帧级 16-bit RPG 动作音效，双遍 `loudnorm` 母带校准至 `-14 LUFS / -1.2 dBTP`，`grain=0` 纯净像素锐度，零右上角/角落水印）。
- **`poster.jpg`**：`1920×1080` 封面海报帧（龙穴拔剑 `VS` 宿命对决，无水印）。
- **`character_sheet.jpg`**：`1920×1080` 八角色头像 + 全身精灵 + 坐骑/道具栏/GPT 龙娘 Boss 设定总表（`?sheet=1`）。
- **`dalabengba.srt`**：46 条精确时间轴外挂歌词字幕（与片内像素歌词条严格同源）。
- **`TREATMENT.md`**：完整导演阐述、调色板 LUT 规范与 26 镜逐拍分镜表。
- **`index.html` & `src/`**：纯代码 16-bit 像素引擎（`px.js`、`glyphs.js`、`timeline.js`、`cast.js`、`ui.js`、`scenes.js`、`main.js`）。
- **`mix.py` & `build.sh`**：一键复现整套可读性门禁、音效合成混音、并行渲染与母带封装脚本。
- **`CREDITS` & `fonts/LICENSE.font.txt`**：字体（Fusion Pixel Font，`OFL-1.1`）与制作署名。
