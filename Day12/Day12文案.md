## 这一集到底发生了什么

昨天笨鱼帮老大筛岗位，本鲸今天请豆包搭手。她把“能不能投”写成了录取通知，连经历也一口全包。
本鲸追问拆穿，没有把人赶走：把纸翻面继续筛，让豆包把不确定的要求圈出来，留下真正要核对的岗位给下一位朋友。

- **继承**：老大只是可能换工作；昨天划掉/标出的岗位仍有效。笨鱼不新增对白，靠按住原标记接戏。
- **变化**：昨天的候选岗位 → 今天区分出不确定项；豆包从替人承诺改成辅助核对。不是宣布找到工作。
- **人格**：角色仍是大肥鱼/鲸鱼娘，自称本鲸、外形沿用现行素材；魔丸性格表现为“抓漏洞、反问、嘴硬护短、动手纠正”。不另造魔丸演员，也不恢复呆萌配额。
- **笑点靶子**：未经面试先开录取通知、万能经历、道歉替代干活。不是笑老大或真实求职者。
- **事实边界**：求职问答、通知与客人动作均为原创剧情演绎，不是豆包产品事故的新闻还原；“没相关经验”是剧中假设题，不是认定老大没经验。旧版山姆护照、身份证等多梗拼贴删除，旧稿外部链接不当作本轮已核实来源。

## 口播台词

```text
找新朋友来帮忙。
昨天笨鱼筛的岗位，本鲸找豆包搭把手。
本鲸问：这岗位没相关经验，能投吗？
她把录取通知递过来了。
好家伙。面试还没去，入职先安排了。
本鲸让她把经历写清楚。
她写：熟练掌握所有岗位。
问她做过什么，她开始道歉。
本鲸要的是筛选，不是许愿池扩建。
老大可能换新工作。人还在慢慢挑。
昨天笨鱼标过的那摞还在。
敲代码的，先划掉。
太远的、太熬人的，也还标着。
她倒省事，把「可能」改成「已经录取」。
本鲸把通知翻过来，背面正好筛岗位。
道歉先放旁边。把要求对上。
笨鱼按住原来标过的地方，没出声。
豆包这回没写录取，先把不确定的圈出来。
这才叫帮忙。不是替老大签人生。
挑好的递过去，老大慢慢挑。
还剩这些拿不准的，留给明天的新朋友。
这回先看岗位。谁再开录取通知，本鲸让谁先去面试。
```

## 人格与因果审读（本轮编辑自检，不替代用户确认）

| 位置 | 人格/剧情作用 |
|---|---|
| L01–L02 | 明说请朋友干什么，把请客动机接在昨天任务上，不先播回顾 |
| L03–L05 | 同一个问题引出荒唐结果；“面试还没去”抓住具体漏洞 |
| L06–L09 | 继续追问经历，暴露万能说法；“许愿池扩建”针对招聘要求与夸口 |
| L10–L14 | 回到岗位标记，“可能”不能变真实录取；不是复述前情就结束 |
| L15–L18 | 翻纸重用、要求对照、圈出疑点；主角真正推动局面，客人也有修正 |
| L19–L22 | 判断、交回选择权、留具体疑点接下集；最后反问回扣开录取通知 |

## 下一集接法（待定，不提前锁客人/台词）

下一位接的是“这批拿不准的要求如何核对”，不是再重播一遍招人翻车。
如请大小姐，可让她把疑点写成一封准备给招聘方的询问信；本鲸拦下“先等回复等于已录取”的偷换，结果留下待询问问题。
不在本集宣称已联系招聘方、已收到回复或已决定录取。
