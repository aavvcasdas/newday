## 这两份文档是什么

- **`ai-girls-memes-and-remotion.md`**：AI 娘同人圈的角色形象、梗词典、关系样本、
  价格/额度等真实机制的公开资料汇总，外加作者提出的世界观与选题建议（第 7、13 节等）。
- **`ai-girls-reference-audit.md`**：主文档引用的 **112 条链接**逐条核查清单，
  记录每条「取到了什么范围、有什么限制」。它的价值不在结论本身，
  而在于**把证据强度摆在明面上**：很多条目只拿到了页面标题/简介，
  有浏览器验证码、HTTP 500、登录壳等失败情况。

1. **三层分开**：现实机制（如 API 峰谷时段）／社区解释（如"吃白饭 = 烧 token"）／
   本次原创桥段，不能混成一层说话。
2. **不是官方设定**：这些是社区与特定作者的作品归纳，角色性格、关系因作者而异，
   不能当某家公司的正史。
3. **没看片不等于看了片**：原文明说视频只读页面文字、未完整观看，
   所以不能把标题当剧情、把简介当画面事实。
4. **产物与素材是两回事**：故事梗概可以借鉴，立绘、音乐、声音、代码的授权要单独核对。
