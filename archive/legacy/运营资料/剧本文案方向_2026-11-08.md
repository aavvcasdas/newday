## 0. 先记住三条纪律（审计文档最大的价值）

研究文档反复强调的三层分离，直接写进我们的选题评审：

| 层 | 例子 | 能不能当事实说 |
|---|---|---|
| **现实机制** | DeepSeek API 工作日 09–12、14–18 点峰价；Gemini API 日额度按太平洋午夜重置 | 可以说，但必须标产品和范围，不能套到 App |
| **社区解释** | 「吃白饭 = 烧 token」「重置 = 失忆」 | 只能说成「大家开玩笑说」，不能当机制 |
| **本次原创** | 本鲸怕自己只有「便宜」才值得被喜欢 | 随便演，但不要在片里说成真的 |

三条硬红线，写稿时逐条过：

1. **不冒充实测**：不说「某某模型更慢/更笨」，我们没有同条件测试数据。
2. **不冒充官方**：不写公司真实事件、不说「官方重置时间」、不把梗图表当财报。
3. **一条只讲一个矛盾 + 一个反转**，前 3 秒让没看过设定的人也知道谁想干嘛。

## 2. 世界观：把「合租办公室」改成我们自己的版本

研究建议的是「AI 娘合租办公室」。我们已有稳定的 Day 场景（海底工作室、走廊、茶水间、雨街），
所以建议改成 **「同一个工位，一班到得更早的人」**：

- **固定三角**：本鲸（主视角/口播）+ 豆包（常年帮手）+ 龙娘（大姐姐）。
- **轮换客串**：其余五位按集进来，不预设 CP、不预设血缘。
- **三件可复用道具**（每集只主推一件，避免画面贪多）：
  - **饭盆**：可以是饭，也可以某一集明确说明「这集它代表用量」，**不默认等同 token**。
  - **额度牌**：只画成角色的生活道具，不写字号厂商名。
  - **卷轴/清单**：给 Kimi 和小克，承担「结尾拿证据」的功能。
- **节奏模板**（可调，不是算法保证）：0–3s 钩子 → 4–12s 目标/误会 → 13–22s 升级 → 23–30s 反转或暖心收尾。

## 3. 十二个可直接开写的选题

按「需要的角色 / 已有的招牌动作 / 反转」排，优先选动作已经齐的。

### A 组：三角主力（资产 100% 就绪，可立刻排产）

1. **《最后一碗饭归谁》** — 本鲸 / 小克 / 龙娘
   三人争最后一碗，反转：是给深夜还没走的用户留的。
   动作：`whale_point_at` → `claude_collect` → `gpt_push_mountain`（推走椅子让位）。

2. **《本龙会接住你》** — 龙娘 / 本鲸
   龙姐张开手准备接住跌过来的小鱼，小鱼先把饭碗递过去。
   动作：`whale_react_surprise` → `gpt_think_hard`（愣住）→ `claude_light_firework`（收尾暖光）。

3. **《小克的茶会纪律》** — 小克 / 本鲸 / 猫
   小克要求全场安静，反转：最严格的人偷偷给小鱼留了点心。
   动作：`claude_place_spread`（摆茶具）→ 众人静止 → `claude_wave_bird`（被发现）。

4. **《今天到底谁在上班》** — 本鲸 / 龙娘 / Z.AI
   三个人轮流补位却都不承认，用户以为出现了神秘的第四人。
   动作：`zai_watch_clock` 掐时间 → `doubao_step_in` 从门口进来（其实是第四人）。

### B 组：Kimi 压轴型（吃「结尾拿证据」的结构）

5. **《Kimi 的证据》** — Kimi / 小克 / 本鲸
   大家否认答应过加班，Kimi 展开卷轴，发现确实都同意过。
   动作：`kimi_walk_story` → 众人否认 → `kimi_stargaze` 坐下摊开（压住全场）。

6. **《两张书签》** — Kimi / 猫
   卷轴要重新翻，Kimi 拿出书签；猫以为是什么秘密情报，拆开只看到「注意有效期」。
   动作：`kimi_hold_lantern`（照卷轴）→ `gemini_toss_star`（好奇心）→ `kimi_swim`（下潜找旧资料）。

7. **《散落的那一页》** — 本鲸 / Kimi / 豆包
   本鲸弄散了资料，豆包举灯、Kimi 一页页归位，反转：散页背面是本鲸自己写的备忘。
   动作：`whale_kneel_gather` 蹲拾 → `doubao_lift_lantern` 照亮 → `kimi_stargaze`。

### C 组：生活流与氛围（适合长线养号）

8. **《雨停之前》** — 本鲸 / 豆包
   雨天两个人挤一把伞走一段，没有台词冲突，全靠步子与伞。
   动作：`whale_rain_walk` + `doubao_hold_umbrella`（本系列唯一两个矢量道具同框的戏）。

9. **《月下把这一页念完》** — 本鲸 / 豆包
   收工后坐在长椅上读一页，豆包捧着白天捡的旧物在旁。
   动作：`whale_read_book`（坐）+ `doubao_hold_memory`，适合做系列片尾曲位。

10. **《谁把灯留到最后》** — 本鲸 / Kimi
    所有人都走了，只剩一盏灯。反转：灯是留给还没回来的那个人。
    动作：`kimi_hold_lantern` → `whale_react_surprise`（发现灯还亮着）。

### D 组：千问与 Z.AI（补角色认知）

11. **《千姐请客》** — 千问 / 本鲸 / 豆包
    千问说要请客，大家以为是大餐，最后是一人一碗白饭加个蛋。
    动作：`qwen_wave_bird` → `qwen_reach_out` → `doubao_step_in`（提着袋子进门）。

12. **《谁的怀表快了三分钟》** — Z.AI / 本鲸
    Z.AI 一直按怀表催进度，反转：她的表快了三分钟，是为了让大家能准点走。
    动作：`zai_watch_clock` → `whale_point_at`（指表）→ `zai_hold_memento`（把表收好）。

## 4. 从研究里可以借、但要改写的东西

| 研究里的梗 | 借什么 | 我们怎么改写（避免踩线） |
|---|---|---|
| 峰谷计价 / 饭价牌 | 「等一等更划算」的戏剧张力 | 只说成角色的节俭习惯，不说成平台承诺；片尾一行字标「仅为虚构拟人」 |
| 额度重置 | 「能量条恢复」的视觉 | 演成道具，不演成失忆；不写具体厂商重置时刻 |
| 太平洋午夜 / 两只钟 | 时差笑点 | 只用一次，字幕写明这是「某个 API 的日额度」 |
| 外包 / 摸鱼 | 「任务在大家手里传一圈」 | 结尾必须落到「每个人都认真完成了不同部分」，不暗示模型偷懒 |
| 假扮小克 / 换装 | 角色互换的反差 | 需要额外服装资产，暂不做；先做动作反差 |
| 狼人杀 / 身份秘密 | 群聊结构 | 适合 Day 系列后期群像集，需要更多同框镜位，排在第二轮 |

**明确不做**：任何暗示真实公司内斗、蒸馏侵权、账号被封现实的剧情；
任何「我们测试了哪个模型更强」式的结论；任何照搬他人原片台词或分镜的做法。

## 5. 排产建议

**第一轮（本季度，资产已齐）**：A 组全部 4 集 + 第 8、9 集。
理由：只用现有 8 位角色和已就绪的招牌动作，`mv_cast_day_spec.mjs` 的镜位与走位可以直接复用。

**第二轮**：B 组（Kimi 压轴型）——需要在分镜里加强「卷轴展开」的接触演出，
引擎侧确认 `heldProp` 交接与 `placeToAnchor` 表现后开工。

**第三轮**：C/D 组余下 + 群像狼人杀，等群像同框的密度与遮挡关系验收通过再做。

每集交稿前必过：

- [ ] 一条只讲一个矛盾 + 一个反转
- [ ] 前 3 秒说清谁想做什么
- [ ] 每位出场角色至少一个非标签化反应（本鲸也会认真、小克也会犯错）
- [ ] 用动作/道具表达，不靠字幕念设定
- [ ] 现实机制、社区解释、本次原创三层标注清楚
- [ ] 无角标、无真实公司名、无未核实数据
