# v10 · 人物动作修复

## 改了什么

针对 v9 中人物几乎看不出动作的问题，以用户指定的参考分支 `arena/e9e1d8ec-newday@2b981a9d8f498db99d2c793f87609dfef914109b` 的固定画布和每格时长为播放方法，保留它的纸艺分镜、字幕和舞台：

- 八名角色为前臂／手建立独立遮罩和背景补画，按固定支点生成 9 个可见角度；不同人物时间错开，另有闭眼格。
- 鲸娘有挥手、难过时伸手两个镜头内动作；「收集快乐」镜头使用用户先前认可的 Day12 舀饭样片图集，手和勺子有不同姿态。其他人物也有自己的手臂帧，不再只动背景。
- 放大相遇、大海等双人镜头中的角色，让肢体变化能在画面中看清。

角色仍是 **固定基线的 2D 剪纸／纸偶动画**：手臂角度通过局部合成生成，不是逐格手绘或原版 pets 动画；没有真正的走路、坐下或完整身体编舞。饭盆出现于收集快乐镜头是创作处理，不是与罐子精确交接。主角姿态随切镜变化，并非镜头内从零开始抬臂。不得把这些限制宣传成完整角色动画。

## 素材与权利

人物使用本项目 `reference-motion`、`lyric-v8`、`whale-pet-study` 中的 Day/Day12/生成素材；Z.AI 挥手及人物手臂下的局部补画是根据这些素材新生成的编辑。未使用或打包上游 pets 原始美术。生成二创不自动授予角色及其他上游权利；非官方同人，发布前须核实。参考分支本身对 pets 原始图像的权利说明也明确不提供统一开放授权。

## 重建与验证

依赖 Python Pillow、NumPy、imageio-ffmpeg 和 Node：

```sh
python tools/mv_extra/v8/setup_v8.py  # 恢复字体和固定来源缓存
python tools/番外MV/动作修复/build_motion.py
python tools/番外MV/动作修复/test_motion.py
cd tools/番外MV/动作修复
npm ci
PYTHON=/path/to/python node --expose-gc render.mjs
/path/to/python verify.py
```

完整输出为 1920×1080、30fps、1681 帧，AAC 从原曲复制。结构测试仅检查局部帧有差异、脚底不变、帧时长有效，**不代表自然度已通过审美验收**。
