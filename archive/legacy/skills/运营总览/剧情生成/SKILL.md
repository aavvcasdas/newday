# Day 连载剧情创作

先读 `agent.md` 的现行覆盖规则；已锁定旧集不改。只请求改稿时不配音、不渲染。

## 输入与顺序

1. **锁定身份与状态**：读 [references/persona.md](references/persona.md)、上一集锁定 TXT、当集方向。确认“没做完什么、谁与谁的关系、不能改的事实”。角色大肥鱼不变，只移植魔丸人格。
2. **选一个矛盾**：开头说找新朋友来帮忙。请客的原因就是上集的未完成任务，允许开头先交代这点动机。不另起话题，一天一位客人。
3. **梗成为障碍**：让朋友实际做一次求职相关的荒唐操作；主角追问使漏洞暴露。不是轮流念“没身份证、豆包味、道歉”。看 [references/beats.md](references/beats.md)。
4. **主角改变局面**：拆穿不是结尾。让她亲手纠正、重用道具、分配任务，使上集的工作向前一小步；未确认事项继续待确认，不编造真实录取结果。
5. **收束并交棒**：写清这次完成了什么、还差什么。下一位朋友接这个具体难点，不每天重播“来了、翻车、不收、换人”。后续来客只是待定方向，非已发生事实。
6. **口播与画面配对**：当集方向逐镜写台词行号、主动作、结果、下一镜接法；未配音只做 `measured=false` 的估时，不伪造正式 cue。外部方法依据见 [references/research.md](references/research.md)。

## 创作入口（不是单独聊天）

```bash
# 不调用模型，检查本轮实际会装载哪些输入，输出可审查的请求包
python3 tools/agent/create_episode.py --day 12 --guest 豆包 --prepare-only
# 已配置 MOWAN_* 时调用模型；只返回待审核候选，不覆盖锁定稿
python3 tools/agent/create_episode.py --day 12 --guest 豆包
```

入口必须一起装载：人设系统提示 + skill 及其引用 + 现行制作规则 + 上集全文 + 当集方向。
没配置模型就报 `unconfigured`，mock 不能作为已完成创作的证据。

## 检查与交付

```bash
python3 tools/剧本/剧情.py --prev Day/Day11/Day11配音台词.txt --card
python3 tools/剧本/剧情.py --prev Day/Day11/Day11配音台词.txt --txt Day/Day12/Day12配音台词.txt --guest 豆包
python3 tools/gate.py --day 12 --stage script
python3 -m unittest discover -s tools/tests -p 'test_*skill.py'
```

脚本只检查顺序、客人数、文本承接信号和红线；通过不等于人设或故事好看。按 persona.md 的人工问题逐项审读，说明对应台词/动作，再交待确认稿。

不按 12/15/18/20/25/201 字退稿，不逐字复制上集来凑命中；不硬塞米缸/读评论/摸鱼。
笨鱼无新增对白；不改老大真实处境；不报无证据数字；不搬同行的形象、配音、点赞关注或竖屏要求。
未核实的梗只标为原创剧情化用，不能当新核实事故，更不能把虚构录取说成产品真实行为。
