配角不是逐帧手绘动画：由静态原图经骨骼网格变形、位移及节拍动作生成，因此部分手部与服饰动作有限。部分人物比例与画风不同。采用 v3 的故事画面作基础并增添人物与纸艺动态，不应把导演规划里的所有细节视为已逐项实现。

验收：视频解码为 1920×1080、30 fps、1681 帧；输出音轨与原音频的 AAC 数据 SHA-256 一致，未重新编码。32 镜各采样两次、每秒选取镜头内两点检查主角及配角动作，全部通过；这不能代替逐帧目视、人耳对歌词节奏的检查。此作品为非官方同人，音乐及角色各自权利独立，公开或商业发布前须另行核实授权。
