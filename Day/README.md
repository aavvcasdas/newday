# Day 口播线

鲸鱼娘第一人称讲当天的事：一句台词一屏字幕，画面是 3D 布景里的像素纸片人。
做法就是 `通用模板/`（`kind: "day"`），这里只放每一集自己的东西。

## 现在有什么

| 集 | 状态 | 说明 |
|---|---|---|
| [`Day14/`](Day14/README.md) 两只沙漏，一张给不出的账单 | **无声样片** | 19 个镜头、44 句。台词沿用重构前写好的那一版；没有配音，卡点是按语速估的，所以只能叫样片 |
| Day0 – Day13 | 已废除 | 重构前做的，成片和工程都在 `存档/重构前/Day/`，不再使用，也没有用新模板重做 |

Day14 同时是这条线的**参考作品**：新的一集照它的写法做（时机挂在句子上、同场景摆位共用、每个镜头看六格）。

## 做新的一集

```bash
npm run new -- day Day/Day15 "标题"      # 从 通用模板/样板/day 起一个新目录
# 1. 写 Day/Day15/台词.txt —— 一行一句 = 一屏字幕
npm run film -- plan  Day/Day15          # 按语速估一份规划轴（measured=false）
# 2. 写 project.tsx 的 planShots（哪一句切到哪个镜头）和 shots/*.ts
npm run film -- sheet Day/Day15 --shot S1,S2   # 写一个看一个：每个镜头从头到尾六格
npm run film -- sheet Day/Day15          # 全片总览
npm run film -- full  Day/Day15          # 出无声样片，给人过分镜
# 3. 配音到位：放进 素材/，film.json 加 "audio": { "file": "素材/配音.wav" }
npm run film -- align Day/Day15          # 按配音实测每句起止（measured=true）
npm run film -- full  Day/Day15          # 出成片
```

每一步的细节、可用的角色造型和道具：`通用模板/README.md` 第五、六节。

## 样片和成片的区别

- **无声样片**（`成片/<标题>_无声样片.mp4`）：没有音轨，每句话的起止是按 3.36 字/秒估出来的。用来过分镜、看构图和节奏，**不能发布**。
- **成片**（`成片/<标题>.mp4`）：有配音，`cues.json` 是按这条配音实测的（`measured: true`，并记着配音文件的 SHA256）。换了配音必须重新 `align`，否则 `full` 会直接拒绝。

配音到了以后镜头不用重写：镜头里的时机都挂在「第几句说到哪」上，卡点变了画面跟着变。

## 这条线的规矩

- **一天一客**：一集只请一位客人上桌，其余角色只在台词里被转述，或作为群像出现。
- 鲸鱼娘自称「本鲸」，全程第一人称。一句不超过 22 个字；数字写成汉字。
- **不加片尾卡**：最后一句说完就结束。
- 画面里不出现运营数字（粉丝数、播放量、金额、百分比、表格、进度条）。沙漏只画沙子，钟只画指针。
- 不给道具画假手；不新增生图；零水印、零角标。
- 想用旧集的台词：从 `存档/重构前/Day/DayNN/` **复制**过来，在新目录里注明出处。存档本身不改。
