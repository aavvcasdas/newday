## 一、电视里放什么（番外真片段，不是重画）

**唯一素材**：本仓库已交付的番外成片 `番外MV/达拉崩吧/dalabengba.mp4`
（`1920×1080`、`24 fps`、`132.77s`、零水印）。

> **重要更正（本轮实测）**：`TREATMENT.md` §5 的 `S01–S26` 秒区间是**制作计划**，与交付成片的实际镜头
> **并不同步**（例如计划里 `128.33–132.77` 写「龙焰烧焦＋十三块石碑」，成片该处实际是
> 「昆图库塔…」名字方块；龙焰喷焦发生在约 `128.4–129.6`）。
> 因此本轮把成片逐 `0.5s` 扫了一遍，**按成片真实画面重新定位片段**，不照抄镜号秒数。
> 成片里也没有找到「十三块石碑砸落」的画面；口播那句是来自 `TREATMENT` 的剧情描述，
> 电视里用「不对!!＋龙焰焦黑」对应「喷成黑炭」，用片尾画面收「片子就完了」，**不虚构石碑帧**。

- **不重画、不新增生图、不截源参考视频帧**：电视里就是这部成片的真帧，按 Day4 先例抽帧后按比例缩小。
  `TREATMENT.md` §3 禁止贴入源参考视频 `达拉崩吧.mp4` 的帧；这里用的是**本仓库自己渲染的成片**。
- **按 `agent.md` 第 13 条**：电视里是**按比例缩小的完整场景**（**v3 缩到 `380×214`**，
  v2 是 `560×315`，v1 是 `920×517`），不是纯色屏上一只孤立角色；不裁掉成片画面。
- **按 `agent.md` 第 17(f) 条**：电视出现后**外框保持稳定**
  （**v3 机身 `(1400,96)–(1840,372)`、屏幕 `(1428,124)–(1808,338)`** 在世界坐标里不变；
  v2 是 `(1100,100)–(1760,500)` / `(1140,130)–(1700,445)`）；
  屏幕内事件与电视外人物的反应按主次先后安排；字幕与常驻声明不随电视剪裁缩放。
  v3 的镜头推近/平移是**摄影机运动**，不是改电视机模型，也不是在屏幕上加控件。
- **不画**：进度条／完成度条／音量条／加载条、播放器按钮、数据曲线、账本表格、角标、水印、片尾卡

  「暂停／倒带」只用**机身旋钮与本鲸的动作**表达，不画屏幕暂停图标或时间码。

  这是**片中片的内容**，不是本集渲染器新增的进度条或数字看板；本集渲染器一行 HUD 都没画。
  为减少占比，`CHEST`／`MOON` 都只取 `2–3s` 短段，不取 `85–101s` 的 `LEVEL UP / 获得金币` 长段。

## 三、抽帧命令（本轮已执行）

本环境无系统 `ffmpeg`，按 `tools/验收/media_common.py` 与 `tools/engine/room_base.mjs` 的既有查找约定，
用 `npm install --no-save --no-package-lock @ffmpeg-installer/ffmpeg @ffprobe-installer/ffprobe` 提供二进制。
抽帧产物 `tools/day14制作/tv_frames/`（10 段共 **442 张 `960×540` JPG，47MB**）被 `.gitignore` 忽略，
可随时重生成；成片、实测轴与渲染脚本入库。

```sh
# 例：BOOK 段，10fps 抽成 960×540 小帧，供画中画按比例缩小到 380×214（v3 小电视；v2 是 560×315）
FF=node_modules/@ffmpeg-installer/linux-x64/ffmpeg
$FF -v error -ss 0.00 -i 番外MV/达拉崩吧/dalabengba.mp4 -t 6.00 \
  -vf "fps=10,scale=960:540:flags=lanczos" -q:v 4 \
  tools/day14制作/tv_frames/BOOK/%04d.jpg
# 其余 9 段把 -ss/-t 换成上表「成片秒」即可；完整可复现命令见 render_day14_video.py 文件头注释
```

**抽帧后已查**（`agent.md` 第 17(h) 条）：成片无水印/角标、电视边框稳定、屏内是完整缩小场景而非孤立角色、
