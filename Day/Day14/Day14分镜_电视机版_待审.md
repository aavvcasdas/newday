## 三、抽帧命令（待排产执行，本轮未跑）

> **本环境没有 `ffmpeg`/`ffprobe`**，因此本页**没有生成任何帧文件、没有解码成片、没有渲染**。
> 下面只是给排产环境的模板，执行前须先核成片 SHA 与 `TREATMENT.md` §5 的秒区间；
> 产物应落在 `tools/day14制作/`（该目录目前**不存在**，不得声称已归档）。

```sh
# 例：取「红皮书翻开」一段，8fps 抽成 320×180 小帧，供画中画按比例缩小
ffmpeg -ss 0.00 -to 8.05 -i 番外MV/达拉崩吧/dalabengba.mp4 \
  -vf "fps=8,scale=320:180:flags=neighbor" -q:v 3 \
  tools/day14制作/tv_frames/S01_%03d.jpg

# 其余片段把 -ss/-to 换成上表「成片秒」列即可；定格镜只取一帧：
ffmpeg -ss 128.90 -i 番外MV/达拉崩吧/dalabengba.mp4 -frames:v 1 \
  -vf "scale=320:180:flags=neighbor" tools/day14制作/tv_frames/S25_charred.jpg
```

**抽帧后必查**（`agent.md` 第 17(h) 条）：成片无水印/角标、电视边框稳定、屏内是完整缩小场景而非孤立角色、
字幕与常驻声明不随电视缩放、脸/手/道具无遮挡、跨镜连续。
没有 Day14 音源，电视片段**默认静音**；不把规划轴当实测轴，不把抽帧说成试剪或整片。
