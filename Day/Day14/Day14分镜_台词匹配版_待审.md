# Day14 分镜｜逐句台词匹配版（v2，小电视 + 全画面动画）

> 2026-11-09 用户反馈：「除了电视机怎么没有动画了，请将电视机变小，并且学习 mv 的分镜
> 根据台词匹配分镜然后重新渲染视频。」本页是**按台词逐句切镜的分镜表**，不是 v1 的 C01–C07 大镜。
> v1 的问题是：电视外只有一张立绘 + 轻微呼吸，画面变化全发生在电视里；
> v2 让电视外也按 MV 的镜头语言动起来。

## 一、向番外 MV 学了什么

[`TREATMENT.md`](../../番外MV/达拉崩吧/TREATMENT.md) §5 的 `S01–S26` 是**每 1–4 句歌词一个镜头**，
每镜明确写「居中特写 / 远景纵摇 / 广角仰拍＋震屏 / 中景推近 / 横移跟拍 / 地图平移 /
锁定画面＋菜单特写 / 定格 / 前景划像 / 重度震屏」，并且镜头跟着**当句歌词的内容**走。
[`dalabengba.srt`](../../番外MV/达拉崩吧/dalabengba.srt) 的 46 条歌词轴就是这些镜头的切点依据。

Day14 没有歌词，但有**实测配音轴**：[`voice_alignment.json`](../../tools/day14制作/voice_alignment.json)
的 24 句 `cue.start/end` 就是本版的切镜点。于是按同样格式，把 24 行台词做成 24 个镜头
`M01–M24`：**每行一句 → 一个景别 + 一段机位运动 + 一个本鲸动作 + 一段电视内真片段 + 切镜效果**。
镜与镜之间**硬切**，不加转场特效（和 MV 的多切镜 RPG 一致）。

## 二、电视变小（对比 v1）

| | v1 | v2（本版） |
|---|---|---|
| 电视机身 | `1060×630`，居中 `(500,130)–(1560,760)` | **`660×400`，右上 `(1100,100)–(1760,500)`** |
| 屏幕 | `920×517` | **`560×315`（16:9）** |
| 腾出的空间 | — | 左侧给本鲸大画面与角色特写，下方给纸、伞、饭盆、抽屉 |

电视机身**在世界坐标里尺寸/位置全程不变**（`agent.md` 17(f)）；镜头推近/平移是**摄影机运动**，
不是把电视机模型改大改小，也不是在屏幕上加控件。Day4 C02 的「小鱼钻进电视」也是同样的摄影机逻辑。

## 四、电视外到底动在哪（v1 没有的）

| 动画 | 做法 |
|---|---|
| 本鲸逐帧动作 | 不再单帧立绘：用 `assets/ai-girls` 的 **8/11/16 帧精灵序列**（指向、读书、拿信、步行、坐下眨眼、抹泪、开心待机）按 `8fps` 逐帧播放；定格镜锁第 0 帧 |
| 镜头运动 | 整数像素 `crop + resize`：推近 / 拉远 / 横移 / 纵摇 / 震屏；镜头内用 ease 插值，跨镜硬切 |
| 切镜特效 | 闪白（切镜后约 `0.1s`）、前景斜带划像、震屏；**没有**进度条/音量条/角标/水印 |
| 环境 | 46 个气泡逐帧上浮、顶部水光缓慢明暗呼吸 |
| 道具 | 笔迹按行数逐条写出、烤焦那张从右上滑入夹好、歪伞缩短收进抽屉、旋钮在「暂停/倒带」时转动、白饭盆在 L23 近景出现 |
| 电视 | 前两句开机亮度渐入、L22 起屏幕渐暗；全程静音画中画 |

**字幕不参与镜头变换**：Day2 对话条在镜头变换与特效之后绘制，固定位置，不随电视或摄影机缩放
（`agent.md` 17(f)）。字幕时间仍来自实测 63 屏，不是估算。

## 五、合规与还没做

- 电视内是**番外成片真帧按比例缩小的完整场景**（第 13 条），不是纯色屏上的孤立角色、不是重画、不截源参考视频帧。
- 成片中段自带游戏 HUD 是**片中片内容**，本集渲染器零新增控件；本集零角标、零水印、无片尾卡。
- 八位本名口径不变（v6），音源/台词/实测轴/字幕轴**一个字未改**；片长仍 `125.200s`、`1080p30`。
- **未获真人观影批准**：镜头节奏、好不好笑、像不像、动态观感仍需你审；门禁与自检不等于批准。
- 未写 `episode.spec.mjs`，通用引擎 `pre-render/final` 门禁未跑；发布授权（音源 likeness、番外原曲、字体、上游图像）另核。
- 复现命令与验收结果见 [`Day14制作记录_克隆配音版.md`](Day14制作记录_克隆配音版.md)。
