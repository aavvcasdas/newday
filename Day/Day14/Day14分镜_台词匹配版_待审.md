# Day14 分镜｜逐句台词匹配版（v3，更小的电视 + 八位人物真走位 + 背景/道具细节动）

> **三次反馈连起来看**：
> ① 「除了电视机怎么没有动画了，请将电视机变小，并且学习 mv 的分镜根据台词匹配分镜然后重新渲染视频。」
>    → v2 做了 `M01–M24` 逐句切镜、电视缩到 `660×400`、电视外镜头运动。
> ② 「**电视机小些啊，人物为什么还是在哪不动，看看之前的人物，让人物和背景以及道具细节动起来，电视机缩小**」
>    → v3（本页，当前成片）：电视再缩到 `440×276`；**之前那批八位人物被请回舞台真正走起来**；
>    背景、道具都按帧做细节动画；镜头幅度收小，人物不再被推出画外。
>
> `C01–C07` 是 v1 的历史大镜结构；v2 的「单人立绘 + 微差分帧 + 1.5–1.78× 屏幕特写」也是历史。
> 本页的 `M01–M24` 是当前逐句分镜，**音源、台词、实测轴、字幕轴、片长一个字未改**。

## 一、向番外 MV 学了什么

[`TREATMENT.md`](../../番外MV/达拉崩吧/TREATMENT.md) §5 的 `S01–S26` 是**每 1–4 句歌词一个镜头**，
每镜明确写「居中特写 / 远景纵摇 / 广角仰拍＋震屏 / 中景推近 / 横移跟拍 / 地图平移 /
锁定画面＋菜单特写 / 定格 / 前景划像 / 重度震屏」，镜头跟着**当句歌词的内容**走。
[`dalabengba.srt`](../../番外MV/达拉崩吧/dalabengba.srt) 的 46 条歌词轴就是切点依据。

Day14 没有歌词，但有**实测配音轴**：[`voice_alignment.json`](../../tools/day14制作/voice_alignment.json)
的 24 句 `cue.start/end` 就是切镜点。24 行台词 → 24 个镜头 `M01–M24`，
每行写明景别 + 机位运动 + 上场人物走位 + 电视内真片段 + 道具细节 + 切镜效果，镜间硬切。

## 二、电视三级缩小（用户连提两次「缩小」）

| | v1 | v2 | **v3（本版）** |
|---|---|---|---|
| 电视机身 | `1060×630`，居中 `(500,130)–(1560,760)` | `660×400`，右上 `(1100,100)–(1760,500)` | **`440×276`，右上角 `(1400,96)–(1840,372)`** |
| 屏幕 | `920×517` | `560×315` | **`380×214`（16:9）** |
| 占画面宽 | 约 55% | 约 34% | **约 23%** |
| 腾出的空间 | — | 左侧给角色、下方给纸与伞 | 左侧与下方整片留给**八位人物走位**、纸、伞、饭盆、抽屉 |

机身**尺寸/位置在世界坐标里全程不变**（`agent.md` 17(f)）；镜头推近是**摄影机运动**，
不是把电视机模型改大改小，也不是在屏幕上加控件。Day4 C02 的「小鱼钻进电视」也是同样的摄影机逻辑。
v3 还把推近幅度由 v2 的 `1.50–1.78×` 收到 `1.00–1.36×`：v2 的屏幕特写会把人物推到画外，
这正是「人物为什么还是在哪不动」的观感来源之一。
