## 1. 三个候选结构（DIRECTOR.md §4）

**A｜继续 v4 的海底房间＋本鲸单机反应。** 优点是电视锁死最容易；缺点是背景仍是一张海底墙，
人物只有一个，必然再次变成「背景没变／原地踏步」。**否决**。

**B｜八位本名全场巡游重演番外。** v3 已做过，被用户判定「一堆人物在走动像动物园」。**否决**。

**C｜把样片真帧切成主画面舞台，按 46 行歌词 / S01–S26 逐句配景，前景只让 2–3 位本名做有因果的互动。** ✔ **选中**
理由：背景会随城堡→王座厅→地图→风车村→月光林→龙穴→终局石碑真的换场景；
人物不再靠步态循环制造动感，而是「谁对谁做了什么、对方怎么反应」；
切点仍由 Day14 实测 `chars_timed` 词点触发，不另造音轴；电视内 v3 内容不动。

## 2. Logline & Arc

- **Logline**：本鲸一边重看昨天那支 16-bit RPG 片子，一边把镜头里谁演了什么逐行补写；
  主画面直接切进样片的歌词场景，让「被漏记的交互」当场发生。
- **Setup**：焦黑收尾 / 红皮书启动 → 王城与巨龙劫走公主 → 应征、报到、长名字、月光、龙焰。
- **Turn**：纸上一个字都没有；按下暂停、倒回去，一帧一帧看，发现「电视里全演过了」。
- **Ending**：关电视、收伞、白饭不改；下一集把装不下的名字一个字一个字塞回框。

## 4. Shot list（24 句 × 实测词点；完整卡片见 STORYBOARD.md）

每镜都有：`WAV cue` / `对应样片 S 镜与歌词行` / `样片真帧背景` / `摄影机运动` /
`前景 2–3 位本名互动` / `实测词点` / `结果停留` / `电视（v3 原样）`。
样片真帧来自 `dalabengba.mp4` 5fps / 640×360 整数缩帧，再 ×3 最近邻铺成主画面；
`SAMPLE_FPS=5`，背景帧号由**歌词 SRT 秒**映射到样片，不按 Day14 句长估造。

摄影机至少用到：`push` / `pull` / `pan_r` / `pan_l` / `tilt_up` / `shake` / `static`，
只变换主画面背景；电视矩形在变换之后固定贴上，并在特效后逐像素贴回。

## 6. Cue map / 音乐网格

- 原片 `119.728 BPM`，`bar = 2.00455s`；歌词 SRT 46 行是样片实测切点，Day14 不重唱歌、不改速度。
- 每个 `MAIN_BG` 段落以 `SRT[a].start → SRT[b].end` 或 S01/S13/S14 的间奏秒为样片时间窗，
  再用 Day14 实测词点把该窗映射到当前句；背景帧在 5fps 真帧上推进，30fps 成片不变速音源。
- 每句至少一个主词点切换背景/互动；结果成形后按 Day12 留 `≥0.35s`，末句 `0.6s`。
- 至少四种摄影机运动分配到不同镜头；`M15` 三连快切仍只发生在电视外特效，电视内三连沿用 v3。
