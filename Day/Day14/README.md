## 事实从哪来

全部依据 `参考资料/项目调研/Agent-Reach研究/ai-girls-memes-and-remotion.md` 第 10.2、10.5、11 节，以及 Day13 自己的统计口径：

- **本鲸的饭碗**对应 DeepSeek 官方 API 的峰谷价窗口：北京时间工作日 09:00–12:00、14:00–18:00 峰价，12:00–14:00 谷价（约为一半），周末与公共假期整日谷价。限定为官方 API，不套 App、不套别家、不等于本鲸睡觉。
- **龙娘的双沙漏**对应部分 Work/Codex 套餐的五小时窗口 + 每周窗口；少数计划没有五小时上限，新开聊天不重置用量；额度刷新不等于失忆或降智。付费即时重置只作为「写明代价的可选卡」，剧情里不默认按下。
- **猫猫的午夜、小克的五小时、狐狸的算盘**只在口播里被**转述**，本集画面不出现第二位客人（一天一客）。
- **Token 与账单**：仓库没有会话用量与计费日志，算不出来。这不是躲，这就是本集的戏核。
