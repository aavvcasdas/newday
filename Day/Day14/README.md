# Day14｜两只沙漏，一张给不出的账单

> **状态：无声样片。** 没有配音，每句话的起止是按语速估出来的（`cues.json` 里 `measured: false`）。
> 它用来过分镜、看构图和节奏，**不是成片，不能发布**。配音到位之后的步骤见最后一节。

这一集同时是 Day 口播线的**参考作品**：新模板下第一部从台词做到样片的口播片，镜头的写法（时机挂在句子上、同场景摆位共用）可以照抄。

## 这一集讲什么

接 Day13 结尾留下的两句话往下走：

- 「账单没在本鲸的碗里，暂时数不出来」→ 鲸鱼娘去找会算账的人，结果发现**谁都拿不出她的账单**。
- 「下次先把伞撑稳，再让大家一起走」→ 结尾重申「先把伞撑稳」，把「让她们自己走两步」留给下一集。

客人只有龙娘一位（一天一客）。猫猫、小克、狐狸只在台词里被转述；七位伙伴在 C11 以群像出现。
台词里每件事的事实依据、口径和边界，写在存档的 [`Day14方向.md`](../../存档/重构前/Day/Day14/Day14方向.md) 里，这次没有改动。

## 和存档里那版分镜的关系

存档的 `Day14分镜_制作版.md` 是给旧的 2D 引擎写的 12 个镜头（C01–C12），绑定的是旧引擎的动作 id，当时没有渲染过。
这里**沿用它的镜号和每个镜头覆盖的台词**，在 3D 布景里重新摆了一遍：

- C03 拆成 C03a（名单特写）和 C03b（龙娘与沙漏）；原来一镜到底约 87 秒的 C12 拆成 C12a–C12g 七个镜头。
- 旧分镜里用到、而新图集没有的造型（举相机、摊手、抱饭盆）没有硬凑：C08 改成相机摆在桌上、鲸鱼娘站在旁边；C11 鲸鱼娘站在台前；C12e 是碗沿着桌面滑到她身前。
- C02 原来是室内（桌上的饭碗往前挪半寸），现在在雨夜的街口：鲸鱼娘指向街那头漏着光的门。饭碗改在 C04 端到门口。
- C04 的「伞沿罩住头顶」：旧工程有一套按像素量净空的检查，新模板里没有。现在的依据只是我看过这个镜头的画面——伞确实罩在她头顶上方，但没有量过。

守住的红线和存档一致：沙漏只画沙子，不画刻度和百分比；不画表格、金额、进度条；不给伞画假手；没有片尾卡；没有角标；画面里唯一的数字是批次条上的「第三十七批」，价签上只有一个「价」字和涨跌箭头。

## 查过什么，没查什么

**机器查过的**（`成片/qa.json`，全部无问题）：5085 帧齐全、尺寸一致、没有空画面、没有冻住的画面、19 个切点都真的切了、44 句字幕条都在场；样片能完整解码。

**我看过的**：每个镜头写完后看了从头到尾的六格（C03a 除外）；出片后把整片按每秒一格抽成胶片条，170 格从头到尾看了一遍；新的分镜总览图也看了。
**出片之后才查出来的毛病（这份样片里还在）**：沙漏翻过去之后会抖。C12a 最明显——1:25.3 到 1:30.0，小沙漏每一帧都在两个倾角之间来回跳；C12b（1:34.2 起）和 C12c（1:51.3 起）沙漏还在画面里的那几秒也有，幅度小一些。每秒一格的胶片条上每一格单看都正常，所以当时没看出来；自检只查「冻住」，不查「抖」。
原因是沙漏翻完之后留着翻转最后一帧的倾角，而两个渲染页面留的角度不一样。源码已经修了（`通用模板/engine/props.ts`，开渲前的预检现在也会报这类问题），**但这份样片没有重渲**；下次 `full`（或者配音到位后出成片）时就没有了。

留着没修的小毛病：

- C05 里镜头推向账本的途中，鲸鱼娘有不到一秒被左边画框切到。
- C12d 是全片最长的镜头（约 21 秒），鲸鱼娘的下半身在对话条后面，地上那摞纸贴着左边缘。
- C11 的七位伙伴站得比较远，人偏小。

**没人做过的**：没有人把样片连续播放看过一遍——每秒一格的胶片条看不出动作顺不顺、节奏对不对。没有配音，所以也谈不上听。

## 配音到位以后

```bash
# 1. 配音放进 Day/Day14/素材/，film.json 加一段：  "audio": { "file": "素材/Day14配音.wav" }
npm run film -- align Day/Day14     # 按配音实测每句起止 → cues.json 变成 measured: true
npm run film -- sheet Day/Day14     # 看一眼总览：卡点变了，镜头长短会跟着变
npm run film -- full  Day/Day14     # 出成片 成片/Day14.mp4
```

镜头不用重写：所有动作和运镜的时机都挂在「第几句说到哪」上，卡点变了画面跟着变。
要注意两点：

- `align` 默认按停顿切句，这套切法**还没有用真人配音验证过**。第一次用，务必对着 `cues.json` 把配音听一遍；有逐词时间戳（Vosk）的话用 `--words`，更稳。
- 配音的语速和估的差得多时，个别镜头可能太短或太长，需要回头调排镜（`project.tsx` 的 `planShots`）。
