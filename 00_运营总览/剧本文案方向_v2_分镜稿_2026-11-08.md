## 0. 写稿前先对齐四件事

### 0.1 结构模板（借用研究第 7 节，我们按 30 秒剪辑）

| 段落 | 时间 | 必须发生的事 |
|---|---|---|
| 钩子 | 0–3s | 一个具体动作 + 一句口语，让没看过设定的人知道谁想干什么 |
| 目标/误会 | 4–12s | 有人提出一个具体诉求（要东西、要人、要答案） |
| 升级 | 13–22s | 至少两人各自坚持，出现可见的"卡住" |
| 反转/收尾 | 23–30s | 反转落在道具或动作上，**不用字幕解说** |

### 0.2 三条硬约束（来自研究第 11 节"表演规则"）

1. **把规则演成道具**，不把道具当事实。饭盆可以是饭，也可以是某一集的用量，
   但**必须在片内用一句台词或一个动作说明是哪一层**，否则观众会把玩笑当机制。
2. **每个角色至少一个非标签化反应**：本鲸也会认真、小克也会出错、龙娘也会缺额度。
3. **作息是虚构编排**：不说"高峰价=变慢"、不说"重置=失忆"、不说"等待=摸鱼"。

### 0.3 我们的口播规则（`agent.md` 早已固定）

- **只有本鲸开口**；其余角色是图集哑演 + 纸条/字幕，不新增声线。
  所以每集的设计要点是：**本鲸一人说，其他七人靠动作把话说回来**。
- 无角标、无真实公司名、无未核实数据。

### 0.4 把选择权交给画面

每集只允许 **1 个主道具 + 最多 2 个招牌动作特写**。
理由：我们引擎里能跟手的矢量道具只有灯笼、伞、纸页、碗这几个；
道具一多，舞台遮挡和层序就会打架（`world_interactions.mjs` 的 `placeToAnchor` 也只保证单点交接）。

## 1. 第一批：三集连拍（资产 100% 就绪）

三集共用「海底工作室 + 走廊 + 茶水间」三个既有舞台，可一次搭景连续拍摄。

---

### E01《最后一碗饭归谁》

- **一句话**：三个人都说是自己留的最后一碗，结果是留给还没下班的那个人的。
- **定位**：系列开场，建立"本鲸 + 豆包 + 小克"三人日常。
- **出场**：本鲸（口播）、豆包、小克。舞台：`pantry_hearth`。
- **主道具**：饭碗（`rice_bowl` → `empty_bowl` 状态切换）。
- **反转帧**：碗底压着一张写着别人名字的纸条。

| # | 时间 | 画面 | 关键 spec 字段 |
|---|---|---|---|
| 1 | 0–3s | 本鲸快步走到桌前，伸手护住碗，回头看 | `locomotion:'walk'` `whale_point_at` |
| 2 | 3–7s | 豆包从右侧提灯进门，把灯放低照亮碗 | `doubao_lift_lantern`（矢量灯跟手） |
| 3 | 7–13s | 小克蹲下要把碗收走，本鲸急得后退半步 | `claude_collect`（crouch 姿态） |
| 4 | 13–20s | 三人各站一边，谁都不先动；灯在中间轻轻晃 | 全员 `idle`，只有灯与阴影动 |
| 5 | 20–26s | 小克把碗推回桌中央，本鲸低头看见碗底纸条 | `claude_wave_bird` → 本鲸 `whale_react_surprise` |
| 6 | 26–30s | 镜头拉到走廊口，龙娘推着晚班的东西刚走进来 | `gpt_push_mountain`（远景剪影） |

- **台词骨架（本鲸独白）**：
  1. "这碗是留给还没下班那个人的。"
  2. "豆包你别照了，照得我心里发慌。"
  3. "小克，你收碗的动作能不能先停一下。"
  4. "我们仨谁都没动，那就都不是自己的。"
  5. "碗底下写了名字……写着龙娘。"
  6. "她还在路上，这碗就得盖上。"

### E02《本龙会接住你》

- **一句话**：龙姐张开手准备接住跌过来的小鱼，小鱼先把饭碗递了过去。
- **定位**：把龙娘从"背景里的强者"变成"会被逗到的人"。
- **出场**：本鲸、龙娘。舞台：`corridor_hatch`。
- **主道具**：饭碗。
- **反转帧**：龙娘双手接住的不是人，是碗；她愣了一下才笑。

| # | 时间 | 画面 | 关键 spec 字段 |
|---|---|---|---|
| 1 | 0–3s | 本鲸抱着碗小跑，脚下一滑往前扑 | `locomotion:'walk'` → `whale_react_surprise` |
| 2 | 3–8s | 龙娘从侧门踏出，双手张开准备接 | `gpt_think_hard`（伸手时的停顿） |
| 3 | 8–14s | 慢镜：小鱼重心前倾，碗先到 | 本鲸 `lean` + 龙娘定格 |
| 4 | 14–21s | 龙娘接住的是碗，人还站着 | `heldProp` 交接：本鲸 → 龙娘 `handoff` |
| 5 | 21–27s | 龙娘托腮看碗，再看向小鱼 | `gpt_think_hard` |
| 6 | 27–30s | 两人并排坐地，碗放中间 | `whale_sit_bench` + 龙娘同镜 |

- **台词骨架**：
  1. "本鲸没摔，本鲸只是有点急。"
  2. "龙娘你别张那么大，接不住会显得我很小。"
  3. "碗先到，本鲸随后到。"
  4. "你接住的是一碗饭，不是你想象的场面。"
  5. "……那你为什么还举着？"
  6. "因为举着好看，坐下吃。"

### E03《散落的那一页》

- **一句话**：本鲸弄散了清单，豆包举灯、Kimi 一页页归位，散页背面是本鲸自己写的备忘。
- **定位**：把两位"帮工"角色立起来，同时给 Kimi 一个压轴出场。
- **出场**：本鲸、豆包、Kimi。舞台：`underwater_study`。
- **主道具**：纸页（`folded_page`）。散落的多张纸由舞台层 `stageTriggers` 做纸面散落，不进 `heldProp`。
- **反转帧**：归好序的最后一页，背面是本鲸的字。

| # | 时间 | 画面 | 关键 spec 字段 |
|---|---|---|---|
| 1 | 0–3s | 本鲸转身撞翻桌上的纸，纸滑了一地 | `whale_react_surprise` + `stageTriggers` 纸面散落 |
| 2 | 3–8s | 本鲸蹲下去捡，越捡越乱 | `whale_kneel_gather`（crouch） |
| 3 | 8–14s | 豆包从门口进来，把灯压低照地面 | `doubao_lift_lantern` |
| 4 | 14–21s | Kimi 提着纸灯登场，一页页比对顺序 | `kimi_hold_lantern` + `kimi_walk_story` |
| 5 | 21–26s | 最后一页翻过来，是本鲸的字 | 本鲸 `whale_point_at`，Kimi 递页 |
| 6 | 26–30s | 三人围着灯把纸按好 | `kimi_stargaze` 收尾（坐姿） |

- **台词骨架**：
  1. "纸是软的，本鲸的手是急的。"
  2. "别捡了，越捡越像下雪。"
  3. "豆包你灯再低一点，我看看这是第几页。"
  4. "Kimi 你从后往前对，那是我的坏习惯。"
  5. "……这页背面怎么是我的字。"
  6. "所以不是丢了，是我自己藏的。"

## 2. 第二批：氛围向两集（适合做片尾或隔周发）

### E04《雨停之前》—— 本鲸 × 豆包，全片几乎不说话

- 舞台：`rain_street`。主道具：伞。
- 两个矢量道具唯一同框的戏：`whale_rain_walk` + `doubao_hold_umbrella`。
- 结构：两人挤一把伞走三段路 → 伞一直往本鲸那边偏 → 最后本鲸把伞推回去。
- **台词只有两句**：开头"伞往你那边偏一点"，结尾"现在轮到我了"。
- 用途：可作为系列的情绪缓冲集，也适合做合集片头。

### E05《月下把这一页念完》—— 本鲸 × 豆包，收工戏

- 舞台：`pantry_hearth`，暖光。主道具：小册子 + 白天捡到的旧物。
- 动作：`whale_read_book`（坐）+ `doubao_hold_memory`。
- 结构：念一页 → 停 → 合上 → 灯还亮着。
- 用途：系列固定片尾，可加可变的那句"今天这页到此为止"。

## 4. 明确不写的（研究里出现过，但我们不采用）

| 研究里的梗 | 为什么不写 |
|---|---|
| 具体价格 / 额度数字对照 | 数字随时变，且原文自己标了"部分仅二手线索"；写进片里就是误导 |
| "重置 = 失忆 / 降智" | 研究第 10.2 节明确这是社区梗，不是机制；写实了会变成不实陈述 |
| "某家模型更慢/更强" | 我们没有任何同条件实测数据 |
| 蒸馏、封号、公司内斗 | 虚构化也容易被读成影射现实事件 |
| 照搬他人原片台词/分镜 | 授权不明，且 `agent.md` 红线禁止复制上游美术与成片 |

## 5. 交稿前检查清单（每集逐条打勾）

- [ ] 前 3 秒有具体动作，不靠字幕解释
- [ ] 只有一个矛盾 + 一个反转
- [ ] 反转落在**道具或动作**上，不是台词说出来
- [ ] 出场角色每人至少一个非标签化反应
- [ ] 招牌动作 id 都存在于 `tools/engine/mv_cast_registry.mjs`
- [ ] 坐/蹲/游的动作没有配走路（`schema_validator` 会拦）
- [ ] 现实机制/社区解释/原创三层标注在制作记录里，不混进台词
- [ ] 无角标、无真实公司名、无未核实数据

## 6. 怎么落到工程上

1. 复制 `tools/engine/day_episode.template.spec.mjs` 到 `tools/dayN制作/episode.spec.mjs`；
2. 把上表的"关键 spec 字段"直接填进各镜 `actors`：
   `characterId: 'claude', action: 'claude_collect'` 这样一行，引擎会自己加载对应图集；
3. 先用 `status: 'planning'` + `createPlanningPreview` 出无声结构片验收动作与走位；
4. 动作通过后再绑音源、建立实测词轴，`status: 'ready'` 才允许正式渲染。
