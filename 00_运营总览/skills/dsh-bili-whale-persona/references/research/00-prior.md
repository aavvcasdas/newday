# 00 · 先验快照（调研前）

> 写于 2026-11-27，调研之前。用途：给后面的提炼当参照物。

## 我对「孙吧人设 + B站鲸鱼」的既有认识

1. 孙吧味 ≈ 抽象话、阴阳怪气、鉴定体、反串、骂人；核心是「损」。
2. B站鲸鱼插件 ≈ 会自己刷视频、写日记、发评论的 agent。
3. 人设 skill ≈ 一段人格描述 + 说话风格。

## 三个我最有把握的事实

- 孙吧语料攻击性很强，直接学一定会带毒。
- B站对评论/私信有风控和频率限制。
- 平台对辱骂、地域、性别攻击是明确禁止的。

## 三个我不确定的

- 孙吧味里到底哪部分是「语言质感」、哪部分是「攻击」，能不能干净切开。
- 插件到底有多少功能（读完 README 才知道有 60+ 命令）。
- 女娲.skill 的「伦理红线」具体卡在哪几条。

## 大众最常见的一句话印象

「孙吧味就是没素质地骂人。」
