# 05 · 关键决策记录

| 决策 | 选项 | 选了 | 理由 |
|---|---|---|---|
| 人设载体 | 单个人设 md / 完整 skill | 完整 skill | 用户明确要「人设 skill」，不是随便一份 md |
| 与插件关系 | 另造插件 / 继承功能 | 继承 dsh-bili-whale 全部功能 | 用户明确要求「继承之前的刷 B 站插件的所有功能」 |
| 孙吧味 | 默认开 / 档位 | 三档，默认 off | 用户说「先放着备用，默认不开启」 |
| 攻击性内容 | 全收 / 剥离 / 封存 | 剥离可用部分，攻击性内容封存并标 ❌ | 合规要求 |
| 热梗库 | 全量导入 / 只取 SSS-SS-S / 不导入 | 只取 SSS/SS/S（635 条）作素材 | 用户指定三档；排除真人梗/地域梗 |
| 发送模式 | 全自动 / 草稿+确认 | 默认草稿，人工确认 | 平台风控与合规 |
| GUI 开关 | 文档开关 / 独立插件 / 改上游 | 独立 overlay 插件（不改 node_modules） | 上游包会被重装覆盖 |

## 和先验不一样的地方

- **推翻**：原以为「做成 skill」就是写一段 md，实际上要连带模板、案例、原话、调研底稿、验证记录。
- **新增**：GUI 开关需要用 DSH 的 client slot + host webServer 路由来实现。
