# 发言三态门禁

对外发言（评论 / 二级回复 / 私信 / 动态 / 弹幕）默认**只出草稿，不自动发**。

## 三态流程

```
① draft（默认）   → 生成草稿，只打印，不调平台写接口
② gate（自检）    → python scripts/check_comment.py --text "<草稿>" --tier <档位>
                     必须 PASS + 人工过一遍 references/boundaries.md
③ go（人工确认）  → 主人当场点头后，才带 --go 真发；一次一条
```

对应插件（dsh-bili-whale）本来就是 `--dry` / `--go` 两段式，本 skill 把「默认停在 dry、go 必须人工点」写死成规矩。

## 硬规矩

- **每一次 `--go` 都要人当场确认**，不能「先答应过就一直发」。
- **一次一条。** 批量、定时、多房间铺量不是这套工具的用途。
- **发完必须回读**（`check-comment` / `thread`），报错或超时就核查，**不许换个措辞重发**。
- **撞风控**（10031 / 12051 / 12015 或验证码中间页）→ 立刻退避、报备。
- **事实没数过就不写数字**；**判断不了就不发**；**没素材就不发**。

## 发布前自检清单（gate 态必过）

1. [ ] `check_comment.py` 返回 PASS（无脏词/攻击词/引战词/真人梗/地域梗/灌水）
2. [ ] 没骂人、没地域/性别/人身攻击（脚本挡不住的，人来挡）
3. [ ] 没贴别人昵称头像、没断章取义
4. [ ] 数字/票数/原句能回溯，查不到就说「没数过」
5. [ ] AI 相关内容该标就标
6. [ ] 短、口语、有立场、没客服腔、没 AI 味

## ⚠️ 关于「全自动发」（高风险，默认关闭）

> 上游 dsh-bili-whale 有自主活动能力，但本 skill **默认关闭自动发送**。
> 这不是免责声明，是真实后果：

- **平台风控**：B 站对高频/批量评论、私信有频率限制和风控；撞上会冷却、限流，严重的**封号**。
- **内容风险**：抽象味一旦滑向辱骂/引战，轻则评论被删，重则账号被投诉、处罚，后果落在**账号主人**身上。
- **不可撤回**：评论/私信发出后可能已被看到、被截图，删了不等于没发生。

### 开启条件（满足才允许）

1. 账号主人**逐条**确认过要发的内容（不是「以后都自动」）；或
2. 主人在插件策略里**显式**把对应动作加进 autoApprove 并接受后果；且
3. 仍然保留：安静时段、每日额度、风控冷却、发后回读。

**本 skill 与 agent 在任何情况下都不得：**
- 默认打开 auto；
- 在无人确认时替主人批量/定时/群发；
- 把「人设需要放开」当作绕过红线的理由。

> 一句话：**默认草稿，人工点发，是这条鲸能一直活着说话的底线。**
