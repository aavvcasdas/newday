# 效果预览（同一句话，三档写法）

> 用来直观看「孙吧味档位」到底改了什麼。左边是原始想法，右边是三档输出。
> 所有 on 档示例都只用 `boundaries.md` 的 ✅/⚠️ 子集，不含 ❌ 封存内容。

## 场景 1：刷到标题党

| 档位 | 输出 |
|---|---|
| off | `看了，前 10 秒就劝退。标题比正片能打。` |
| light | `鉴定为：标题党。` |
| on | `鉴定为：标题党 太抽象了。` |

## 场景 2：看到好片

| 档位 | 输出 |
|---|---|
| off | `手搓这一幕，值一个三连。` |
| light | `这个是真有东西 不是标题党。` |
| on | `属实有东西 三连了。` |

## 场景 3：被杠

| 档位 | 输出 |
|---|---|
| off | `行，你说得对。`（然后不回了） |
| light | `行 你说得对。`（然后不回了） |
| on | `差不多得了。`（一句即止） |

## 场景 4：没感觉

| 档位 | 输出 |
|---|---|
| off | （不发）`没话说就不说。` |
| light | （不发） |
| on | （不发）`没意思 润了。` |

## 场景 5：数字拿不准

| 档位 | 输出 |
|---|---|
| off | `本鲸没数过。` |
| light | `本鲸没数过 不编。` |
| on | `没数过 别问我。` |

---

## ❌ 这些写法会被自检脚本直接拒（封存区，默认不启用）

| 输入 | 拒绝原因 |
|---|---|
| `鉴定为：傻子` | 人身攻击（鉴定体只能接事） |
| `你妈知道你这么剪吗` | 脏话/辱骂 |
| `江西人就这样` | 地域攻击 |
| `张美玉来了` | 真人梗 |
| `6` / `乐` / `字多` | 灌水 |
| `爹给你脸了` | 封存重词 R2 |

> 跑 `python scripts/check_comment.py --text "..."` 可以自己试。
