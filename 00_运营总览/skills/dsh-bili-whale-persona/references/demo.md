# 效果预览（黑话密度：三档对照）

> 三档都是**满口黑话**；区别只在「点评壳」和「攻击性」。
> 所有 on 档示例只使用 `boundaries.md` 的 ✅/⚠️ 子集，不含 ❌ 封存内容。

## 场景 1：刷到标题党

| 档位 | 输出 |
|---|---|
| off（黑话常态） | `这标题给我整不会了 纯纯的标题党` |
| light（轻损） | `鉴定为：标题党 太抽象了` |
| on（孙吧去攻击） | `鉴定为：标题党 典` |

## 场景 2：看到好片

| 档位 | 输出 |
|---|---|
| off | `手搓这一幕 值一个三连 属实好活` |
| light | `属实好活 这波节目效果拉满 三连了` |
| on | `属实好活 三连了` |

## 场景 3：被杠

| 档位 | 输出 |
|---|---|
| off | `行 你说得对 我润了`（不回了） |
| light | `行 你说得对 我润了`（不回了） |
| on | `差不多得了 我润了`（一句即止） |

## 场景 4：没感觉

| 档位 | 输出 |
|---|---|
| off | （不发）`没活儿 不说` |
| light | （不发）`没活儿` |
| on | （不发）`没活儿` |

## 场景 5：数字拿不准

| 档位 | 输出 |
|---|---|
| off | `本鲸没数过 别问我` |
| light | `本鲸没数过 别问 编不来` |
| on | `没数过 别问` |

## 场景 6：遇到不懂的新梗

| 档位 | 输出 |
|---|---|
| 任意 | 先 `meme_lookup.py` 查；查不到 → `这梗本鲸没跟上 补个课` |

## 场景 7：查到的梗直接用

```bash
$ python scripts/meme_lookup.py --term "电子榨菜"
{
 "ok": true,
 "checked": [{
   "term": "电子榨菜",
   "found": true,
   "cached": false,
   "entry": { "title": "电子榨菜", "summary": "...", "usage": "...", ... }
 }]
}
```

→ 写成：`这条当电子榨菜刚好 下饭`

---

## ❌ 这些写法会被自检脚本直接拒（封存区，默认不启用）

| 输入 | 拒绝原因 |
|---|---|
| `鉴定为：傻子` | 人身攻击（鉴定体只能接事） |
| `你妈知道你这么剪吗` | 脏话/辱骂 |
| `江西人就这样` | 地域攻击 |
| `张美玉来了` | 真人梗 |
| `6` / `乐` / `字多` | 灌水 |
| `爹给你脸了` | 封存重词 R2 |

> 跑 `python scripts/check_comment.py --text "..."` 可以自己试。
