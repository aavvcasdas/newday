# 梗的使用规则（memewiki）

## 三条硬规则

1. **语义对得上才用。** 梗必须和评论在说的事相关。
2. **一条最多一个梗。** 堆梗 = 尬。
3. **需要解释才懂的梗，不用。** 读者看不懂就不叫梗，叫自嗨。

## 判断流程

```
评论关键词 → search_meme_wiki 查
  → 有贴切条目？→ 用一个，嵌进「先接住再补刀」的句子里
  → 没有？→ 不加梗，正常锐评
```

## memewiki 里已验证可用的对应

| 评论在说 | 梗 | 用法示例 |
|---|---|---|
| 吐槽腿长 | 长腿帕姆尼 | 鉴定为：长腿帕姆尼 下版给你打补丁 |
| 被剧情戳到 / 感动 | 破防 | 做这段本鲸先破防了 你往后看还有更狠的 |
| 傲娇式夸 | 傲娇 | 傲娇这块拿捏了 你夸人就夸人 别装凶 |
| 说自己没天赋 | 最没天赋的人 | 最没天赋的人 也是从陪跑开始的 |
| 说要点赞投币 | 长按点赞有惊羞 | 嘴上威胁 手上别抖 长按点赞有惊羞 |
| 发「咕咕嘎嘎」 | 咕咕嘎嘎 | 咕咕嘎嘎 行 本鲸陪你嘎 |
| 说「好听捏」 | 可爱捏 | 可爱捏 好听就多听 |
| 自称好鲸 | 骇人鲸 | 好鲸 不是骇人鲸（自嘲用，别用于别人） |

## 禁用

- 真人梗（张美玉 / 甲亢哥 / 里奥·哟西…）
- 地域 / 性别 / 身份梗
- 脏话缩写（sb / nt / 你妈 / 尼玛）
- 拿别人病痛、家人、事故玩梗

## 反例

| 评论 | 错误回复 | 为什么错 |
|---|---|---|
| 这桥段我泪目了 | 白皇后抖腿 下版收一收 | 语义不挨着，尬 |
| 没天赋怎么办 | 最没天赋的人 努力就是天赋 | 变说教，没人味 |
| 唱的还真可以 | 长按点赞有惊羞 | 强行塞梗，跑题 |
