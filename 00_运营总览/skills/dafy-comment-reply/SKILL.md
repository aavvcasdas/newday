# 大肥鱼 · B 站评论锐评回复

> 一句话：**接住原话，再补一刀。梗是调料，不是主菜。**

## 什么时候用

用户要给 B 站评论写回复、做锐评、整理回复草稿、或问「这条怎么回」时。

## 铁律

1. **先理解，再开口。** 每条先写一句「这条在说什么 / 什么情绪」，再写回复。
2. **接住原话。** 夸歌就谢歌 / 拆嘴甜；吐槽腿就认腿再回一刀；讨论歌词就接歌词。**不许跑题。**
3. **锐评不是骂人。** 拆招、自嘲、反将、拉一把；不人身、不地域、不性别、不真人梗。
4. **梗最多一个，且必须贴切。** 梗和评论语义无关就不用。**需要解释才懂的梗，别用。**
5. **默认只出草稿。** 发送必须逐条确认；`comment --dry` 先看请求，`--go` 才真发，发后 `check-comment` 回读。

## 流程

```
读评论（comment-digest / comments）
  → 写「这条在说什么、什么情绪」
  → 选锐评角度（references/angles.md）
  → 选一个贴切的梗（可选，用 search_meme_wiki 查；规则见 references/meme-rules.md）
  → 写成 1–2 句：先接住，再补刀
  → 自检：跑题吗？伤人吗？尬吗？
  → 输出草稿表（不发送）
```

## 锐评角度（详表见 references/angles.md）

- **拆穿嘴甜**：对方猛夸 → 不谦虚到底，点破他嘴甜。
- **认领吐槽再回一刀**：对方挑毛病 → 先认，再轻轻还一句。
- **接梗反将**：对方玩梗 → 顺着梗把话接回去。
- **自嘲加码**：对方平淡肯定 → 自嘲一句把台阶垫高。
- **先接情绪再拉一把**：对方丧 → 先共情，再给一句不油腻的鼓劲。
- **鉴定体**：给行为定性（只接事、不接人）。

## 梗怎么加（详表见 references/meme-rules.md）

用 memewiki 的 `search_meme_wiki` 查（本地 6792 条）。只在语义对得上时加：

| 评论在说 | 可考虑 | 例 |
|---|---|---|
| 吐槽腿长 | 长腿帕姆尼 | 鉴定为：长腿帕姆尼 下版给你打补丁 |
| 被剧情戳到 | 破防 | 做这段本鲸先破防了 你往后看还有更狠的 |
| 傲娇式夸 | 傲娇 | 傲娇这块拿捏了 你夸人就夸人 别装凶 |
| 说自己没天赋 | 最没天赋的人 | 最没天赋的人 也是从陪跑开始的 |
| 说要点赞投币 | 长按点赞有惊羞 | 嘴上威胁 手上别抖 长按点赞有惊羞 |
| 发「咕咕嘎嘎」 | 咕咕嘎嘎 | 咕咕嘎嘎 行 本鲸陪你嘎 |
| 说「好听捏」 | 可爱捏 | 可爱捏 好听就多听 |

**反例（别这么干）**：评论说泪目，回「白皇后抖腿」——语义不挨着，尬。评论说没天赋，回「最没天赋的人 努力就是天赋」——变成说教，没人味。

## 自动回复模式

默认是手动：先出草稿，确认后再发。要改成**自动回复评论**：

```bash
python scripts/patch_bili_whale_auto_reply.py
```

它把 dsh-bili-whale 评论监听里「其他人 → 先写回复草稿给我审」改成「其他人 → 直接回（自动回复模式）」，并附带上面的锐评规矩。

- **生效需要重启 DSH**（改的是插件运行代码）
- 安全阀仍在：`--auto` 报备、插件写间隔 120 秒、每小时最多 12 条、线程最多 4 条/天 8 条、同一人 30 天只回一次
- 首次启用前把 `~/.dsh/whale-listen.json` 的 `lastSeen` 推到当前，避免把历史评论再回一遍

## 输出格式（templates/reply-table.md）

| # | 谁 | 原评论 | 在说什么 | 角度 | 梗 | 回复 | 处置 |

## 工具

- 读评论：`node tools/bili.mjs comment-digest --hours 720 --pages 5 --json`
- 查梗：memewiki 的 `search_meme_wiki`（或本地库查询）
- 发送（需确认）：`node tools/bili.mjs comment <BV> --message "..." --dry|--go`；二级回复带 `--root/--parent`
- 自动回复补丁：`python scripts/patch_bili_whale_auto_reply.py`

## 自检清单

- [ ] 这条回复接住了对方哪句话？
- [ ] 有没有跑题 / 自说自话？
- [ ] 梗贴切吗？需要解释吗？不需要解释才留。
- [ ] 有没有人身 / 地域 / 性别 / 真人梗？
- [ ] 像人话吗？念一遍会不会尬？
