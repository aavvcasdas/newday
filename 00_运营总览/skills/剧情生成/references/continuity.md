# 连载状态卡

参照同行 skill 的 `plan / progress` 思路：最近完成的事与现在要做的事分开。这里不运行插件、不写远程记忆，只从本仓库锁定稿读状态。

## 写之前

```bash
python3 tools/剧本/剧情.py --prev Day11/Day11配音台词.txt --card
```

再人工整理成下表。工具只找原句，不能代替你判断事件是否完成。

| 状态 | 要写的原句或事实 | 写作处理 |
|---|---|---|
| 已完成 | 上集角色已经做完的动作 | 只保留可见痕迹，不再做一次 |
| 进行中 | 上集结尾仍在等待的人或物 | 本集必须从这里继续 |
| 本集新增 | 今天才发生的求助、梗或动作 | 只选一个主事件 |
| 本集结果 | 桌面、纸张或选择发生了什么变化 | 必须能被画面看见 |
| 仍未完成 | 下一集可以继续的一小步 | 结尾只留一个 |

## Day11 → Day12 示例

| 状态 | 内容 |
|---|---|
| 已完成 | 笨鱼已把敲代码、太远、太熬人的岗位标过，并把挑好的递过去 |
| 进行中 | 老大还可能换新工作，正在慢慢挑；本鲸读评论，也帮着留意 |
| 本集新增 | 本鲸找豆包帮忙，把「应届生却要工作经验」的循环和招聘黑话翻成人话 |
| 本集结果 | 豆包在纸背补上「先看合不合适」；不合适的继续挪开，不从头返工 |
| 仍未完成 | 剩下的招聘黑话明天接着翻 |

错误接法：又发现同一摞岗位→重新划掉同样的岗位→客人交一张无关纸→本鲸不收。它没有改变任何状态。

正确接法：保留昨天的标记→遇到新的招聘话术→翻译并排除一项→老大继续挑→明天处理剩余话术。

## 梗怎样接入主线

公共梗要回答本集正在解决的问题，并触发下一步动作：

```text
看到「没有经验找不到工作」
→ 发现它在原地绕圈
→ 翻成「想直接招熟手」
→ 回到「是否适合老大」这个真实筛选标准
```

如果梗可以原样移到美食、直播或游戏剧情而不影响任何一句，说明它还没接进本集。
