# 剧情生成

先读 `agent.md`。不读不写。本 skill 决定剧情怎样生成；`agent.md` 仍决定事实、素材、配音与合规边界。

可运行入口：

```bash
python3 tools/agent/run.py --skill 剧情生成 --day 12 --guest 豆包 \
  --message "重写 Day12：开头找新朋友帮忙，用求职梗接回昨天的岗位"
```

未配置模型时入口会如实返回 `unconfigured`。不得把人工写稿冒充远程 Agent 已生成。

## 一、按顺序装三层，不把三层揉成一段人设

参照同行 `dsh-douyinxiaoqi` 的 `persona / style / plan / progress` 分工，但只借结构，不装载它的主人、账号、插件行为或大肥鱼身份。

1. **稳定人设**：读 `references/persona.md`。管「本鲸遇到事会怎么反应」，不管今天必须发生什么。
2. **上集状态**：读上一集锁定口播，按 `references/continuity.md` 写承接卡。区分「已经做完」和「还留在桌上」，不能让角色把做完的事重新做一遍。
3. **当集任务**：读 `DayN/story_card.json`（有则必读）。写清今天的求助对象、公共梗、实际行动、可见结果和下一步。没有卡就先补卡，不直接凑台词。

人设层不能因为换题目就消失；剧情层也不能靠反复念「我是魔丸」「本鲸绝不摸鱼」冒充人设。

## 二、先写事件链，再写台词

在草稿前先用五行回答：

```text
上集没完的事：谁还在等什么？
本集开头行动：本鲸现在找谁、来做什么？
公共梗：哪个陌生人也听得懂的处境或循环？
推进动作：本鲸和客人具体改变了桌上哪件东西？
本集结果／下集钩子：哪件事有了新状态，哪件事留给下一集？
```

五句必须能连成因为→所以。删掉其中一句后如果剧情毫无变化，那一句大概率是装饰，不是剧情。

### Day12 指定顺序

1. 第一句就说 **找新朋友来帮忙**，不能先让她迟到、道歉或办无关证件。
2. 立刻说明 **帮老大挑工作**，让「帮忙」有对象、有任务。
3. 用 **求职公共梗** 制造冲突。本集采用「招应届生，却要求工作经验；先工作攒经验，又绕回没有工作」的循环。它是虚构岗位纸上的公共求职调侃，不冒充某家公司真实招聘原文。
4. 梗之后必须回到 Day11 的同一摞岗位：笨鱼已经标过程序、距离和强度，老大还在慢慢挑。**不重头再筛，不推翻上集。**
5. 今天新增的动作是 **把招聘黑话翻译成人话，继续缩小选择**。豆包也要留下有用结果，不能只负责递梗。
6. 结尾留下「明天接着翻剩下的招聘黑话」，不再预告一串还没轮到的新客人。

## 三、一集只推进一个事件

同行 Day 系列可复用的是结构，不是原句：

- 「找工作／学技能／做游戏」这类连载，每集标题对应一个具体结果；失败也推进状态。
- 高粉账号 DayN 之后常把评论、身份或关系做成一次验证、比赛或共同任务，而不是念前情。
- 本集只讲「新朋友帮忙翻译岗位」，不同时讲护照、封号、模型排名、价格、米缸危机和未来客人名单。

禁止以下伪推进：

- 把 Day11 的筛选条件重新念一遍，没有任何新动作。
- 客人说完梗就走，本鲸只评价「离谱」「不收」。
- 连续写「她没碰、她不收、她再来一句道歉」，桌上状态始终不变。
- 为接下一集，在结尾提前点名多位客人。

## 四、台词怎么像本鲸

- 本鲸是唯一口播。客人只能递纸条、夹页或名牌；本鲸可以念纸上的字，不另配客人声线。
- 魔丸落在判断和行动里：不被招聘话术带着绕，不跪、不反省、不解释自己换了谁；对事不对人。
- 短句不是目的。该让观众看懂因果时就把因果说完整，不恢复 12/15/18/20/25/201 字退稿。
- 零句尾语气词；不卖萌，不写客服腔，不喊「首先／其次／总之」。
- 笨鱼继续哑演。老大不是程序员，白天上班；只写「可能换新工作」，不承诺已经找到。

## 五、写完做两类验收

### 结构门禁

```bash
python3 tools/剧本/剧情.py \
  --prev Day11/Day11配音台词.txt \
  --txt Day12/Day12配音台词.txt \
  --guest 豆包 \
  --story-card Day12/story_card.json
python3 tools/gate.py --day 12 --stage script
python3 -m unittest tools.tests.test_plot_skill tools.tests.test_mowan_agent
```

`story_card.json` 会检查求助开头、求职梗、上一集原句、实际推进、客人结果和下一集钩子。关键词通过只代表结构骨架齐，不代表笑点或审美自动合格。

### 人工语义验收

逐项回答「是／否」，任何一项为「否」就改稿：

- 不看前集，能否听懂「帮谁、做什么、卡在哪」？
- 看过前集，能否指出今天比昨天新完成了什么？
- 梗是否推动后续动作，而不是另一集突然插进来的广告？
- 本鲸的判断是否符合稳定人设，又没有攻击老大、求职者或客人？
- 客人是否帮上了忙，结尾是否只留一个可兑现的下一步？

完成锁字前保持 `measured=false`。不得根据字数生成正式字幕或宣称已配音、已渲染。
