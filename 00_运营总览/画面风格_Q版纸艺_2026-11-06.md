## 画面：纸艺立体书

参照 `Win-Hao/music-mv`（MIT）的 diorama 配方，代码为本仓库自有实现（`tools/engine/paper_stage.mjs`）：

- 纸边、刀口、纸厚投影（偏移剪影，**不用逐帧 blur**，否则软渲染 ~5s/帧）；
- 6–8 层分层视差与景深，暖光自左上；
- 道具 **12fps 手摆**（定格感），镜头一次慢推 ≤7% 后锁死；
- 场景预设 `sea_room`（海底书桌）/ `shore`（岸）/ `dusk_hill`（夕照坡）；
- 道具 `desk` / `bowl` / `sheet` / `sign` / `plant` / `puzzle`。

**景别必须真的改变构图**，不是只改标签：
`wide 1.0` / `two_shot 1.06` / `medium 1.2` / `close 1.45` / `insert 1.6`（各带取景中心）。
字幕与角标在取景变换之外绘制，不随推近放大。

## 人物与动作：pets 真逐帧

角色库 `tools/角色Q版库/`，打包成 pets 自描述格式 `pets/<id>/spritesheet.png + pet.json`
（网格 / 行状态 / 每帧毫秒 / 公共脚底），结构参照上游 `FORMAT.md`，**非官方协议**。

硬规则：

- 整格 192×208 绘制；**禁自动裁切 / 逐帧居中 / 拉伸**，归一化只在打包期做一次；
- 按 `pet.json` 毫秒播放；非循环动作停在末帧；公共 `footY` 切状态不跳位；
- **禁止整图弹跳**冒充动态：`idleMotion` / `livingBody` / `bodyEvents` 与 bounce/hop/sway/squash 一律拒绝；
  动态来自**真帧表演 + 走位 + 道具 + 镜头 + 光**；
- 动作只能引用图集里**真实存在**的状态；未生成的状态直接报错，不得冒充已有动作；
- 有走位必须配 `walk-*` 真步态，禁止平移滑行。

## 同屏 ≤2 人（硬门禁）

`tools/engine/paper_contract.mjs` 的 `MAX_ON_SCREEN = 2`：任一时刻超过 2 人**直接抛错**，渲染不出来。
同一角色不得重复上场。要第三人就**拆镜**或**让角色退场**，不得靠缩小人物塞满画面。

## 流程与验收不变

先估时 → 分镜 → 关键镜有声试剪 → 整片；逐镜写构造细节（准备→接触→结果→反应→停留）。
无指定音源只能 `status=planning` / `measured=false` 的**无声结构样片**，出 mp4 须显式 `--silent-planning`，
画面自带 `无声规划样片 · measured=false` 标识，并写 `<out>.render.json`。
正式 cue 只能来自实测 ASR＋RMS。

沿用不变：Day2 字幕组件、BGM 规则（第22条）、尾部 0.24s、无片尾卡、
锁定台词/音源/语速不改、画面红线体检（禁数字/账本/进度条/粉丝数）。
`tools/gate.py --day N --stage script|audio|pre-render|final` 四阶段门禁照旧。

**结构检查、图集校验、全片解码都不等于视觉/听审验收。**
