要让仓库真正瘦下来，需要单独做一次历史重写（`git filter-repo`）+ 全员重新克隆，
这是破坏性操作，等你明确同意再做。

## 3. 现在的目录纪律

1. **视频音频不进 Git**，除非是登记过的交付成片。
2. 交付成片放 `DayN/成片/` 或 `番外MV/<作品>/成片/`，不要扔仓库根目录。
3. 中间产物（抽帧、试剪、缓存 WAV）走 `.gitignore`，放 `/tmp` 或对应 `cache/`。
4. 需要固定素材时，登记 SHA-256 + Git blob，用 `setup.py` / `restore_*.py` 还原，不要重复提交本体。
