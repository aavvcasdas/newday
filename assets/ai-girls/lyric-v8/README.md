# v8 歌词动作图集素材

`whale` 是 Day12 鲸娘；`claude` 使用固定版本 Day12 既有姿态；`doubao`、`gemini`、`gpt`、`kimi`、`qwen` 沿用此前 Q 版形象。这里的每人 PNG/JSON 均是本项目编排的固定单格帧图集（384×416），不是参考 Pet 仓库的美术文件。

`source/` 中：鲸娘的站立、闭眼、挥手、捧拼片和陪伴姿态，以及五位配角的记忆拼片/比心姿态，是本轮基于先前形象用 AI 辅助生成并抠除绿背景；相应挥手源图由 v6 生成图复用。Whale 行走、仙女棒/相机和 Claude 行为从已固定的 Day12 旧姿态构图；五名配角站姿来自 `chibi-v5`，GPT 闭眼来自 `pet-v7`。重建时 Day12 缓存由 setup 恢复。具体权利边界和来源见各上游素材 README 以及 Day12 资产记录，生成衍生图不自动取得第三方权利。

同一角色的本轮编辑共用原始画布；来自不同历史姿态的 PNG 尺寸不同，已按比例放入共同固定格，不能称为完全逐帧配准。每行包含重复持帧，普通配角主要是站姿、挥手与展示/比心关键姿态，鲸娘和 GPT 有闭眼帧；并非每人都具备完整的手绘逐帧动画。`sha256.json` 校验产出的七套图集及元数据。
