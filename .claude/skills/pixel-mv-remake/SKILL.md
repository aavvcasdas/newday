# Pixel MV Remake & Surpass（AI娘轻像素立体书/RPG 番外MV复刻超越规范）

本技能沉淀自《达拉崩吧》v1→v4 与《童话镇》番外 MV 的完整迭代定版经验，基于 `lemo-opuscar` 的纯代码像素渲染引擎，将任意参考歌曲 MV 升级为**本仓库 AI 娘全员出演、轻像素高辨识度、1–2 秒闪电入书、全程高频多场景切镜**的 `1920×1080 @ 24fps` 正式成片与配套封面文案。

## 二、双层分辨率「轻像素」清晰度标准（拒绝糊成马赛克）

用户明确要求：**「人物不需要这么模糊，稍微模糊点就好了」**。必须采用双分辨率帧缓冲架构（`px.js` `FB` + `FB.hi`）：

1. **世界与 UI 逻辑层（`320×180`，`×6` 整数临近放大 → `1920×1080`）**：
   - 用于天空渐变抖动（Bayer 4×4）、远山城堡、河面倒影、像素建筑摊位、RPG 边框与位图字幕，保证正统 16-bit 超任像素质感。
2. **角色高清晰度轻像素层（`640×360`，`×3` 整数临近放大 → `1920×1080`）**：
   - 全身角色精灵采用 `88px`（常规）与 `148px`（近景 `scale >= 2`）高度，地图 Q 版鲸鱼娘采用 `56px` 高度，头像采用 `64×64`（存入 `32×32` 窗口的 `.hi` 层）。
   - 完整保留发饰、眼神高光、裙摆层次与代表性配饰，呈现「清脆轻像素化」而非糊成色块。
3. **纯净锐度封装**：
   - 调用 `mux.sh` 时第 5 参数 `grain` **必须设为 `0`**，禁止叠加胶片噪点破坏像素边缘。

## 三、节奏与场景密度铁律（1–2 秒入书 + 杜绝站桩与枯燥前奏）

针对参考样片常见的「开头书本静止 8–12 秒」「间奏空镜干走」「每段剧情前摇空旷」痛点，执行以下硬标准：

1. **1–2 秒闪电跃入立体书（严禁漫长开场等待）**：
   - **`0.00s – 1.10s`**：木质书桌快速建立氛围，必须摆放有叙事温度的像素道具（承接 Day13 正传的**热气「老大的白饭」瓷碗**、摇曳烛台、羽毛笔墨水瓶、红蓝魔药或星盘），Q 版鲸鱼娘自左侧小跑冲向红皮金边立体书；
   - **`1.10s` 起跳 → `1.65s – 1.85s` 翻页入画**：鲸鱼娘腾空跃入书页，金光粒子炸开，直接切入像素大世界第一镜！
2. **前奏 / 间奏 / 吟唱段高频多切镜（每 `2.5s – 4.0s` 换景，绝不干等唱歌）**：
   - 凡超过 `4s` 的纯音乐前奏、间奏或尾奏吟唱（如 `啊~~` 段），必须拆分为 **3–6 个连续推进的子场景**（如：启航码头 → 三摊位热闹集市 → 冒险公会/工坊 → 王城远眺；或暮色观星台 → 孔明灯升空 → 折纸船登彩虹 → 童话星座连线）。
3. **每镜「前-中-后」三层景深与丰富物件**：
   - **前景**：流动河面波纹与倒影、发光折纸小船队、石桥灯柱、芦苇花丛；
   - **中景**：主角本鲸持续位移（乘船引航、跨桥奔跑、潜水、拔剑/举灯）+ 当句对应 AI 娘的明确戏剧动作（逃跑追蝶、披风旋涡、倒茶、攀豆藤弹竖琴、丢玻璃鞋等）；
   - **后景**：多层视差远山、城堡尖塔、旋转风车/水车、时光瀑布（怀表/日历/音符坠水）、浮空岛或现实高楼倒影。

## 四、简体中文像素字库 100% 烘焙门禁（零缺字框 `▯`）

任何出现在 `timeline.js`（歌词字幕 `SUBS`）、`scenes.js`（招牌/对话框/UI 标签）、`main.js`（角色设定表）中的字符，必须在 `src/glyphs.js` 的 `8px / 10px / 12px` 三套字号中全部存在：

1. 编写完分镜与字幕后，运行本技能自带的自动字形烘焙脚本：
   ```bash
   node .claude/skills/pixel-mv-remake/scripts/bake_glyphs.mjs "番外MV/<歌名>"
   ```
   该脚本自动扫描 `src/**/*.js` 的全部字符，利用 `@fontsource/fusion-pixel-{8,10,12}px-monospaced-sc` 的精确 `unicode-range` 子集在无头浏览器中栅格化缺失汉字并写回 `src/glyphs.js`，自动拦截空字形或豆腐框。
2. 渲染整片前必须通过 `lemo-opuscar` 可读性门禁：
   ```bash
   node "$LEMO_OPUSCAR/core/render/readcheck.mjs" "番外MV/<歌名>"
   ```

## 五、标准生产流水线与合规交付清单

### 1. 环境一键初始化（容器重启后必跑）
沙盒仅放行 `github.com`、`registry.npmjs.org`、`pypi.org`，直接运行：
```bash
sh .claude/skills/pixel-mv-remake/scripts/bootstrap.sh
```
自动就绪 `/home/user/lemo-opuscar`、FFmpeg 7+/9+（支持 `mux.sh` 的 `alimiter=latency=1`）、`ffprobe`、`chrome-headless-shell` 与动态库路径 `/home/user/bin/libs/lib`。

### 2. 抽帧分析参考样片（先实测，后排轴）
- 用 `ffprobe` 实测参考 MP4 的精确时长、帧率、音频采样率与 SHA256；
- 抽取全片缩略图联系表与逐秒底部歌词条联系表，精确锁定每句歌词起止时间（误差 `≤ 0.15s`），从源视频提取原速无损 PCM 参与混音（绝不变速、绝不截断尾音）。
- **彻底剥离参考片右上角平台水印**：全片 100% 由像素引擎原生绘制输出，成片与封面均严格执行**全局零水印新规（`agent.md` 第 34 条）**。

### 3. 先静帧多点目检，再全量渲染
- 在正式跑 `video.mjs` 前，先用 `still.mjs` 渲染 12–20 张覆盖开场入书、集市、副歌全景、水下/夜景、高潮与合书结尾的 `1920×1080` 预览帧，用 `read_file` 逐张目检确认：**零文字重叠、零缺字、公主确系 Claude 而非豆包、地图小人确系鲸鱼娘、画面饱满不空旷**。

### 4. 目录标准交付物（`番外MV/<歌名>/`）
- `<slug>.mp4`：`1920×1080 @ 24fps`、`-14 LUFS` 母带校准（原曲 + 帧级同步 16-bit 场景音效，`grain=0`）；渲染后必须从编码后的 `.mp4` 直接抽帧复检。
- `<slug>.srt`：与片内像素歌词条严格同源的外挂字幕。
- `poster.jpg` & `character_sheet.jpg`：`1920×1080` 高光剧照与 `?sheet=1` 全员轻像素设定总表。
- `封面/<歌名>MV_封面_3比4.png`（`1080×1440`）与 `封面/<歌名>MV_封面_4比3.png`（`1440×1080`）+ `make_covers.mjs` + `封面/封面_验收.json`（零水印、零播放/粉丝数字、零进度条、安全边距自动核验）。
- `发布文案.md`（承接最新 Day 正传梗位的主推标题、备选标题、简介与本鲸口吻置顶评论）、`TREATMENT.md`、`README.md`、`build.sh`。
- 验收完毕后清理临时目录，提交并推送到当前会话固定工作分支。
