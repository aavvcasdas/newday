# Newday · 统一视频制作框架

Day 系列与 MV 从现在起共用基于 `remotion-fix-and-mv-recreation.zip` 的 three.js + Remotion 框架，现行使用说明：**[tools/story-framework/README.md](tools/story-framework/README.md)**。

- 新 Day 通用示例：`tools/story-framework/templates/day.spec.ts`、`day.entry.tsx`
- 新 MV 通用示例：`tools/story-framework/templates/mv.spec.ts`、`mv.entry.tsx`
- 网页《童话镇》代码：`tools/story-framework/src/entry.tsx` 及相关镜头文件，用作框架来源及示例，不表示新版成片已审核。
- 文案：`文案/Day/` 与 `文案/番外MV/`；唯一现行 Day 文案模板见 `remade.md`。
- 历史：`archive/legacy/`。旧 skill、工具、模板和制作文档均退役；旧视频成片/试片已从当前分支删除，标题和发布文案保留。参考歌曲视频及音频也已从当前树移除，角色素材保留。删除不等同于从 Git 历史抹除。

**注意：**新框架是可运行的基本骨架，不自动完成剧情、复杂动作、词级同步、听审或动态审片。Day 和 MV 模板目前均为无配音、未实测的演示，须针对实际作品制作与验收。
